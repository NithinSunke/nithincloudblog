Deploy a VM on Oracle VirtualBox with Terraform

By Sunke Nithin · May 20, 2024   LABTerraformVirtualBox

Terraform isn't only for clouds. With the community terra-farm/virtualbox provider it can create VirtualBox VMs from a Vagrant box, so a Home LAB VM is one terraform apply away. Here I deploy an Oracle Linux 7 VM prepared for 19c.

Prerequisites

  • VirtualBox and Terraform installed (see Install Terraform on Windows)
  • A Vagrant box file — e.g. an Oracle Linux 7 box from the Vagrant registry (HashiCorp Vagrant boxes) or Oracle's yum.oracle.com/boxes, downloaded as oel7.box
The provider is unmaintained. terra-farm/virtualbox has seen no release since its 0.2.2 alpha and doesn't work with every VirtualBox version. It's fine for experiments; for a dependable LAB, Vagrant itself (vagrant up) or Proxmox with the Terraform provider for Proxmox are better choices.

1Project Folder

Create a folder (oel), and put the box file and main.tf in it.

2main.tf

HCL
terraform {
  required_providers {
    virtualbox = {
      source  = "terra-farm/virtualbox"
      version = "0.2.2-alpha.1"
    }
  }
}

resource "virtualbox_vm" "node" {
  name   = "ol7_19c_vagrant"
  image  = "oel7.box"              # Vagrant box file in this folder
  cpus   = 3
  memory = "4096 mib"

  network_adapter {
    type           = "bridged"
    host_interface = "Intel(R) Ethernet Connection I217-LM"   # exact name of your host NIC
  }
}

output "ip_address" {
  value = virtualbox_vm.node.network_adapter[0].ipv4_address
}

The bridged adapter name must match your host's network adapter exactly:

CMD
# list host adapter names for host_interface (Windows)
"C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" list bridgedifs | findstr /b Name

My original output used element(..., 1), which picks a second adapter that doesn't exist; the VM has one adapter, at index 0.

3Init, Plan and Apply

BASH
terraform init
terraform plan
terraform apply          # type yes
terraform output ip_address

init downloads the provider; apply imports the box and starts the VM, which then shows up in the VirtualBox Manager. Log in with the box's default credentials (often vagrant/vagrant) and change them.

BASH
terraform destroy        # removes the VM again
