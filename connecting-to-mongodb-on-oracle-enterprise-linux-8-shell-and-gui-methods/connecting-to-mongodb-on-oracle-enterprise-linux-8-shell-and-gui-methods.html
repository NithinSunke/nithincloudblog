Connecting to MongoDB on Oracle Enterprise Linux 8: Shell and GUI Methods

By Sunke Nithin · August 25, 2025   DatabaseMongoDBLinux

Following the earlier post on installing MongoDB on Oracle Enterprise Linux 8 (OEL 8) and creating an admin user, this guide shows how to connect to your MongoDB database using both the command-line shell (mongosh) and a graphical tool, MongoDB Compass. We'll use the admin user (mongoadmin) to demonstrate secure connections. It assumes MongoDB 8.0 is installed on OEL 8 with the Red Hat Compatible Kernel (RHCK) and authentication enabled.

Method 1 — mongoshCommand-line shell. Best for scripting, automation and quick operations.
Method 2 — MongoDB CompassGraphical interface. Best for browsing data and visual database management.

1Prerequisites

  • MongoDB 8.0 Community Edition installed on OEL 8.
  • An admin user (mongoadmin) created with a secure password.
  • The MongoDB service running (sudo systemctl status mongod).
  • An internet connection to download MongoDB Compass (for the GUI method).
  • For remote connections: bindIp set in /etc/mongod.conf (e.g. 0.0.0.0) and port 27017 open in the firewall.
  • Administrative privileges (root or sudo) to install tools.

2Method 1: Connecting Using the MongoDB Shell (mongosh)

mongosh is a powerful command-line interface for MongoDB. Follow these steps to connect as the admin user.

Step 1Verify the MongoDB Service

Make sure MongoDB is running:

BASH
sudo systemctl status mongod

If it's inactive, start it:

BASH
sudo systemctl start mongod

Step 2Connect to MongoDB

Use mongosh to connect as mongoadmin:

BASH
mongosh -u mongoadmin -p --authenticationDatabase admin
OptionMeaning
-u mongoadminThe admin username.
-pPrompts for the password (the one set when the user was created).
--authenticationDatabase adminThe database where the user is defined.

Step 3Verify the Connection

Run these commands to confirm you're connected:

MONGOSH
db.version()   // MongoDB server version, e.g. 8.0.13
db             // current database, e.g. admin

Step 4Perform a Test Operation

Switch to a new database and insert a document:

MONGOSH
use myDatabase
db.myCollection.insertOne({ name: "Test User", role: "Admin" })

The mongoadmin user has readWriteAnyDatabase privileges, so it can work in any database. To view the inserted document:

MONGOSH
db.myCollection.find().pretty()

Step 5Exit the Shell

MONGOSH
exit

Remote Connection (Optional)

If MongoDB is configured for remote access (check bindIp in /etc/mongod.conf and that port 27017 is open), connect from another machine:

BASH
mongosh -u mongoadmin -p --host <OEL8_SERVER_IP> --port 27017 --authenticationDatabase admin

Replace <OEL8_SERVER_IP> with your server's IP address.

3Method 2: Connecting Using MongoDB Compass (GUI)

MongoDB Compass is a graphical tool for managing MongoDB databases, ideal if you prefer a visual interface.

Step 1Download and Install MongoDB Compass

  1. Download: visit the MongoDB Compass download page and pick the build for your operating system — Linux for a local OEL 8 machine, or Windows/Mac for remote management. For OEL 8, download the .rpm package (e.g. mongodb-compass-1.44.6-x86_64.rpm as of August 2025).
  2. Install on OEL 8: copy the .rpm to your server (e.g. with scp), then install it, accepting any GPG key prompts:
    BASH
    sudo yum install -y ./mongodb-compass-1.44.6-x86_64.rpm
  3. Launch: if OEL 8 has a desktop environment, start Compass:
    BASH
    mongodb-compass
    If you're managing the server remotely, install Compass on your own machine (Windows, Mac or Linux) instead.

Step 2Connect to MongoDB

  1. Open MongoDB Compass.
  2. In the New Connection window, enter the connection string:
    URI
    mongodb://mongoadmin:<password>@<OEL8_SERVER_IP>:27017/?authSource=admin
    Alternatively, open Advanced Connection Options → Authentication, choose Username/Password, and enter mongoadmin, the password and admin as the authentication database.
  3. Click Connect. If it succeeds, Compass shows the instance with databases such as admin, config and local.

Step 3Explore and Manage Databases

  • Use the Compass interface to browse databases, collections and documents.
  • Test it by creating a new database (e.g. myDatabase) and collection (e.g. myCollection) from the GUI, then inserting a document:
JSON
{ "name": "GUI Test", "role": "User" }

4Troubleshooting

Shell connection issues

ProblemWhat to do
Authentication failedCheck the username (mongoadmin), the password and --authenticationDatabase admin. If the password is forgotten: temporarily remove security.authorization from /etc/mongod.conf, restart MongoDB, reset the password, then re-enable authentication.
Connection refusedMake sure MongoDB is running (sudo systemctl status mongod) and, for remote connections, that port 27017 is open (commands below).
BASH
# Check which ports are open
sudo firewall-cmd --list-ports

# Open port 27017 if needed
sudo firewall-cmd --add-port=27017/tcp --permanent
sudo firewall-cmd --reload

# Check the MongoDB log for errors
sudo tail -n 50 /var/log/mongodb/mongod.log
While authentication is disabled for a password reset, anyone who can reach the port has full access. Do it with remote access blocked, and switch authentication back on straight away.

Compass connection issues

  • Make sure the connection string includes ?authSource=admin.
  • For remote connections, verify bindIp in /etc/mongod.conf and that port 27017 is reachable.
  • If Compass won't launch on OEL 8, install the common GUI dependency: sudo yum install -y libXScrnSaver.

5Security Notes

  • Always use a strong password for the mongoadmin user.
  • For production, enable TLS/SSL for encrypted connections (see the MongoDB documentation).
  • Limit remote access with firewall rules that allow only specific IP addresses.

Conclusion

You've now connected to MongoDB on OEL 8 with both the mongosh shell and the MongoDB Compass GUI. The shell is ideal for scripting and quick operations, while Compass offers a friendly interface for visual database management. For advanced tasks like replica sets or sharding, see the MongoDB documentation.
