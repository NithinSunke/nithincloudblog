Steps to Add Database Connections to Oracle GoldenGate 23ai

By Sunke Nithin · June 25, 2024   ReplicationOracleGoldengate

Before GoldenGate can capture or apply anything, it needs stored credentials for each database it connects to. In GoldenGate 23ai these live under DB Connections in the Administration Service. This post adds connections for a source CDB and its PDBs, tests them, and adds schema-level supplemental logging (trandata).

prepare database→add credential→connect→add trandata→verify

0Prepare the Database

The database side needs to be ready for GoldenGate first. On the source CDB (19c in this lab), as SYSDBA in CDB$ROOT:

SQL · SOURCE CDB
ALTER SYSTEM SET enable_goldengate_replication = TRUE SCOPE = BOTH;
ALTER DATABASE FORCE LOGGING;
ALTER DATABASE ADD SUPPLEMENTAL LOG DATA;

CREATE USER c##ggadmin IDENTIFIED BY "<password>" CONTAINER = ALL;
GRANT CONNECT, RESOURCE TO c##ggadmin CONTAINER = ALL;
EXEC DBMS_GOLDENGATE_AUTH.GRANT_ADMIN_PRIVILEGE('C##GGADMIN', container => 'ALL');

The database must be in ARCHIVELOG mode for an Integrated Extract. Check the GoldenGate documentation for the exact privileges for your database version.

1Add a Credential

Log in to the deployment's Administration Service as ggadmin, open DB Connections in the left menu and click +:

FieldValue
Credential DomainOracleGoldenGate
Credential AliasA short name you'll use in parameter files, e.g. ORCLCDB
User IDC##GGADMIN@(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=ol8doct01.scslabs.com)(PORT=1521))(CONNECT_DATA=(SERVER=DEDICATED)(SERVICE_NAME=ORCLCDB))) — or user@host:port/service
PasswordThe c##ggadmin password

I added one alias per container I need: ORCLCDB and CDB19C for the CDB roots, and HRDB and ORCLPDB1 for the PDBs.

2Test the Connection

In the Actions column, click the Connect to database icon:

If the credentials and connect string are right, GoldenGate logs in and opens the connection's page.

All four connections added.

3Add Schema Trandata

Connect to the source alias and open Trandata. Choose Schema, click +, enter the schema as PDB.SCHEMA — HRDB.HR here — and submit:

Search for HRDB.HR to confirm: 2 tables prepared, with scheduling columns logged.

Schema-level trandata also covers tables created in the schema later, which is what makes adding new tables to ongoing replication straightforward.

Admin Client equivalent:

ADMIN CLIENT
DBLOGIN USERIDALIAS CDB19C DOMAIN OracleGoldenGate
ADD SCHEMATRANDATA HRDB.HR
INFO SCHEMATRANDATA HRDB.HR
