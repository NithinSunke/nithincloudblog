How to Configure Windows to Display a Message When Users Log On

By Sunke Nithin · August 16, 2025   WindowsGroup Policy

A logon banner — the notice users must acknowledge before the sign-in screen — is a common security and compliance requirement. Windows has two Group Policy settings for its title and text.

1Open the Policy Editor

Press Win+R, type gpedit.msc and press Enter (accept the UAC prompt). secpol.msc opens the same settings directly. Both need Pro, Enterprise or Server editions — on Home use the registry method below.

2Find the Two Settings

Computer Configuration → Windows Settings → Security Settings → Local Policies → Security Options:

  • Interactive logon: Message title for users attempting to log on
  • Interactive logon: Message text for users attempting to log on

Enter a title (e.g. Authorized Use Only) and your text. Both must be set for the banner to appear.

3Apply

CMD · AS ADMINISTRATOR
gpupdate /force

Sign out or lock the PC — the banner shows before the logon screen, and the user clicks OK to continue.

Sample Banner Text

A neutral template; replace the placeholders, and have your legal or compliance team approve the final wording:

TEXT
*** WARNING ***

This computer system is the property of <Company Name> and is for
authorized use only.

By logging on you agree to comply with the <Company Name> Acceptable
Use Policy. You have no expectation of privacy on this system: all
activity may be monitored, recorded and disclosed to authorized
personnel and, where required, to law enforcement.

Unauthorized or improper use may result in disciplinary action and
civil or criminal penalties.

If you do not agree to these terms, log off now.

Other Ways to Set It

  • Domain-wide: set the same two settings in a GPO linked to the computers' OU (Group Policy Management, gpmc.msc). See Windows Server administration LAB.
  • Registry (any edition):
CMD · AS ADMINISTRATOR
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v legalnoticecaption /t REG_SZ /d "Authorized Use Only" /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v legalnoticetext /t REG_SZ /d "This system is for authorized users only. Activity may be monitored." /f
The text box takes plain text only. Keep it short enough to read on the logon screen; very long banners get a scroll bar.
