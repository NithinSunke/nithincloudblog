Oracle GoldenGate 21c Installation – Step-by-Step Guide

By Sunke Nithin · April 26, 2025   ReplicationOracleGoldengate

Oracle GoldenGate 21c moves data in real time between databases. This guide installs the Microservices Architecture on Linux: the software with the Oracle Universal Installer, then a Service Manager and a deployment with the configuration assistant (oggca.sh).

Prerequisites

ItemRequirement
Operating systemOracle Linux or Red Hat Enterprise Linux 7 or 8 (CentOS 7 works for testing but isn't certified)
DatabaseOracle Database 11.2.0.4 – 21c (the 21c "for Oracle" build covers these)
Software213000_fbo_ggs_Linux_x64_Oracle_services_shiphome.zip from Oracle Software Delivery Cloud or the GoldenGate downloads page
OS packagesunzip, libaio, libnsl
JavaNone needed — the installer and oggca.sh use the JDK bundled with GoldenGate
DisplayAn X display (VNC, MobaXterm, X forwarding) for the GUI installers
You don't need gcc/make or a separate Java 11 install for GoldenGate 21c — I listed them in my original post, but the software ships with its own JDK.

1Prepare the Environment

Create the OS user and group (skip if the oracle user already exists from a database install) and the packages:

BASH
sudo groupadd oinstall
sudo useradd -m -g oinstall oracle
sudo passwd oracle

sudo yum install -y unzip libaio libnsl      # on OL8 libnsl is a separate package

Create the directories — one for the software (ogg21c_ma1), the Service Manager (ogg21c_sm1), the deployment (ogg21c_deploy1) and the metrics datastore:

BASH
sudo mkdir -p /u01/app/oracle /opt/soft
sudo chown -R oracle:oinstall /u01/app /opt/soft
sudo chmod -R 775 /u01/app
cd /u01/app/oracle
mkdir ogg21c_ma1 ogg21c_sm1 ogg21c_deploy1 datastore
My lab directory was mistyped as datasore, which is the path you'll see in the screenshots. Any name works as long as you use the same one in the configuration assistant.

2Install the Software

As oracle, unzip the media and start the installer:

BASH
su - oracle
unzip -q 213000_fbo_ggs_Linux_x64_Oracle_services_shiphome.zip -d /opt/soft
cd /opt/soft/fbo_ggs_Linux_x64_Oracle_services_shiphome/Disk1
./runInstaller

Installation Option — Oracle GoldenGate for Oracle Database 21c (it covers earlier supported versions too). Software Location — /u01/app/oracle/ogg21c_ma1:

Review the summary, click Install, and wait for it to finish:

If the installer asks for it (first Oracle software on the server), run the inventory script as root:

ROOT
# as root, if this is the first Oracle product on the server
/u01/app/oraInventory/orainstRoot.sh

3Create the Service Manager and a Deployment

Run the configuration assistant from the software home's bin directory:

BASH
export OGG_HOME=/u01/app/oracle/ogg21c_ma1
cd $OGG_HOME/bin
./oggca.sh

Service Manager Options — create a new Service Manager in /u01/app/oracle/ogg21c_sm1, tick Register Service Manager as a system service/daemon, and set the host and port (9100). Then choose Add new GoldenGate deployment:

Deployment Details — name orclgg01, software home ogg21c_ma1. Deployment Directories — /u01/app/oracle/ogg21c_deploy1:

Environment Variables — OGG_HOME, LD_LIBRARY_PATH and TNS_ADMIN are filled in; set TNS_ADMIN to where your tnsnames.ora lives. Administrator Account — the ggadmin web user:

Security Options — I left SSL/TLS off for the lab; enable it for anything beyond a test box. Port Settings — Administration 9101, Distribution 9102, Receiver 9103; I also ticked Enable Monitoring for the Performance Metrics service (9104) with the BDB datastore:

Replication Settings — the default schema for the GoldenGate admin user (c##ggadmin in a CDB). Review the summary and click Finish:

During Configure Deployment it asks you to register the Service Manager as a service. Run the script as root, then click OK:

ROOT
# as root, while the oggca dialog waits
/u01/app/oracle/ogg21c_sm1/bin/registerServiceManager.sh

4Start and Stop the Services

registerServiceManager.sh creates a systemd unit, so the Service Manager — and the deployment with it — starts at boot:

BASH
sudo systemctl status OracleGoldenGate
sudo systemctl stop OracleGoldenGate
sudo systemctl start OracleGoldenGate

5Verify

Open the Service Manager at http://<host>:9100 and log in as ggadmin. All four services of orclgg01 should be running:

From the Administration Service (port 9101) you can now add database connections and create Extract and Replicat processes.

Tip: keep the GoldenGate software home separate from the deployment home, as here. Patching or upgrading is then just installing a new software home and pointing the deployment at it.
