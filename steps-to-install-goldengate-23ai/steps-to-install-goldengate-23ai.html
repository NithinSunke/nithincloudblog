Steps to Install Oracle GoldenGate 23ai Microservices

By Sunke Nithin · June 25, 2024   ReplicationOracleGoldengate

In this post we install Oracle GoldenGate 23ai (23.4) Microservices on Oracle Linux 8: install the software with the Oracle Universal Installer, create the Service Manager and a deployment with oggca.sh, register the Service Manager as a system service, and log in to the redesigned web console.

unzip→runInstaller→orainstRoot.sh→oggca.sh→registerServiceManager.sh→web console

0Assumptions

  • Oracle Linux 8 is installed, with an oracle user in the oinstall group.
  • The GoldenGate 23ai for Oracle software (V1042871-01.zip) is downloaded from Oracle Software Delivery Cloud or My Oracle Support.
  • An X display is available for the oracle user — the installer and oggca.sh are GUIs.
23ai is the Microservices-only release: the Classic Architecture is gone, so every install looks like this one. Oracle has released newer GoldenGate versions since this was written; the installer and configuration flow are much the same, but check the latest release on the download page and apply the latest bundle patch.

1Copy and Unzip the Software

cd /u01/soft/
unzip V1042871-01.zip

2Install the GoldenGate Software

BASH · ORACLE
cd /u01/soft/fbo_ggs_Linux_x64_Oracle_services_shiphome/Disk1
./runInstaller

Choose the option for Oracle Database 23ai and lower, set the software location to /u01/app/ogg/ogg_home, and the inventory to /u01/app/oraInventory with group oinstall:

Run the inventory script as root, then click OK:

BASH · ROOT
/u01/app/oraInventory/orainstRoot.sh

3Create the Service Manager and Deployment

BASH · ORACLE
cd /u01/app/ogg/ogg_home/bin
./oggca.sh

The 23ai assistant is shorter — 7 steps — and splits the Service Manager and the deployment into separate pages:

StepSetting
Service Manager deploymentDeployment home /u01/app/ogg/ogg_sa, host 192.168.1.12, port 7000, register as a service/system daemon, StatsD remote metrics on port 7001
Service Manager administratorggadmin with a strong password
User deploymentName oprod, home /u01/app/ogg/ogg_deploy, ports 7002–7005, replication schema C##GGADMIN
User deployment administratorSame as the Service Manager administrator

oggca.sh steps 1–5.

Lab vs production: security is disabled here, so the consoles run over plain HTTP. For anything beyond a lab, enable security with server and CA certificates (TLS 1.3 is available in 23ai).

Register the Service Manager as a service

Click Finish. The assistant explains that it will stop the deployment, have you run a registration script, and then start the Service Manager as a daemon:

BASH · ROOT
/u01/app/ogg/ogg_sa/bin/registerServiceManager.sh
OUTPUT
OGG_HOME=/u01/app/ogg/ogg_home
OGG_CONF_HOME=/u01/app/ogg/ogg_sa/etc/conf
OGG_VAR_HOME=/u01/app/ogg/ogg_sa/var
OGG_USER=oracle
Running OracleGoldenGateInstall.sh...
Created symlink /etc/systemd/system/multi-user.target.wants/OracleGoldenGate.service → /etc/systemd/system/OracleGoldenGate.service.

Check the service, and open the ports if you'll connect from another machine:

BASH · ROOT
systemctl status OracleGoldenGate.service

firewall-cmd --permanent --add-port=7000-7005/tcp
firewall-cmd --reload

4Log In to the Web Console

Browse to the Service Manager on port 7000 — http://ogg23c.scslabs.com:7000 — and sign in as ggadmin. The 23ai console is redesigned: the Service Manager and the oprod deployment both show as running, and expanding the deployment lists its four services.

Click Administration Service (port 7002) to open the deployment's Admin console, where you create Extracts and Replicats.

Scripting it: save the response files from the Summary screens and rerun with ./runInstaller -silent -responseFile … and ./oggca.sh -silent -responseFile … for repeatable installs.
