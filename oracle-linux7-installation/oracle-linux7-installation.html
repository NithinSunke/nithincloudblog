Oracle Linux 7 Installation

By Sunke Nithin · June 13, 2019   Linux

A walkthrough of installing Oracle Linux 7 (formerly Oracle Enterprise Linux) in a VMware Workstation virtual machine — creating the VM, choosing the software, partitioning the disk, and finishing the first-boot setup.

Version note (2026). Oracle Linux 7 has reached the end of Premier Support and only gets Extended Support. It's still fine for practising with older Oracle Database releases, but use Oracle Linux 8 or 9 for anything new. The installer (Anaconda) looks almost the same on all three, so these steps carry over.

1Download the ISO

Download the latest Oracle Linux 7 update ISO (the full DVD image) from yum.oracle.com or Oracle Software Delivery Cloud (edelivery.oracle.com). Use the newest update (7.9) rather than an early one like 7.1 — it has years of fixes already in it.

2Create the Virtual Machine

  1. In VMware Workstation choose File → New Virtual Machine → Typical and click Next.
  2. Select Installer disc image file (iso), browse to the Oracle Linux 7 ISO and click Next.
  3. Enter a name for the VM and the folder to keep it in.
  4. Set the maximum disk size (40 GB or more if you'll install Oracle Database) and choose whether to store the virtual disk as a single file or split it. Click Next, then Finish.
  5. Click Edit virtual machine settings: give it at least 2 GB of memory (8 GB if it will run a database), the processors your hardware allows, and a Bridged network adapter so the VM gets an address on your home network.

3Start the Installer

Power on the VM, select Install Oracle Linux 7.x and press Enter. Pick your language and click Continue.

4Installation Summary

  • Date & Time — set your time zone.
  • Installation Source — Local media.
  • Software Selection — choose Server with GUI and these add-ons:
    • Java Platform
    • KDE (optional — GNOME is the default desktop)
    • Compatibility Libraries
    Pick whatever your environment needs; for a database server, Server with GUI plus Compatibility Libraries is a good start, and the oracle-database-preinstall RPM adds the rest later.
  • Network & Host Name — switch the adapter On and set the host name, so the network comes up at boot.

5Partition the Disk

Click Installation Destination, select the disk, choose I will configure partitioning and click Done. Choose Standard Partition (or LVM) and use + to add mount points. A sensible layout for a 40 GB lab disk:

Mount pointSizeFile system
/boot1 GBxfs
swap4 GB (or equal to RAM up to 16 GB)swap
/20 GBxfs
/u01the restxfs — Oracle software and data
Don't give the rest of the disk to swap. In my original lab I made / about 37 GB of ext4 and put everything else into swap. Swap only needs to be about the size of RAM (Oracle's installer checks it against memory); extra swap is wasted space. XFS is the default and recommended file system on Oracle Linux 7 — ext4 works but there's no reason to change it. A separate /u01 keeps Oracle files from filling the root file system.

Click Done and Accept Changes.

6Install

  1. Click Begin Installation.
  2. While it installs, set the root password and use User Creation to add a normal user.
  3. When it finishes, click Reboot.

7First Boot

  1. Accept the licence agreement and click Finish Configuration.
  2. For registration choose No, I prefer to register at a later time; you don't need ULN — the free public yum repositories are enough (see the related post below).
  3. Sign in with the user you created, step through the welcome screens and click Start using Oracle Linux Server.

If the VM is on a working bridged network, the internet is available straight away. Check with:

BASH
ip addr
ping -c 3 yum.oracle.com
sudo yum update -y
