Shell Script to Automate Database Creation in Oracle Database 19c

By Sunke Nithin · August 16, 2025   AutomationScripts

Creating a database through the DBCA GUI is fine once; for labs and repeatable builds, a script is better. This one runs DBCA in silent mode to create an Oracle 19c database — either a non-CDB or a CDB with one PDB — with no GUI and no response file.

  • Database name, CDB/non-CDB and PDB name come from arguments (with defaults).
  • Passwords come from environment variables or a hidden prompt — they're not stored in the script.
  • One DBCA call with shared options, so the two modes can't drift apart.

create_db.sh

CREATE_DB.SH
#!/bin/bash
#
# Script : create_db.sh
# Purpose: Create an Oracle 19c database with DBCA in silent mode
# Usage  : ./create_db.sh [DB_NAME] [CDB_FLAG] [PDB_NAME]
#          e.g. ./create_db.sh orcl19c true pdb1
#

# ========= CONFIGURABLE VARIABLES =========
export ORACLE_BASE=/u01/app/oracle
export ORACLE_HOME=$ORACLE_BASE/product/19.0.0/dbhome_1
export PATH=$ORACLE_HOME/bin:$PATH

DB_NAME=${1:-orcl19c}       # Global database name
DB_SID=$DB_NAME             # SID
CDB_FLAG=${2:-false}        # true = CDB with one PDB, false = non-CDB
PDB_NAME=${3:-pdb1}         # PDB name (if CDB_FLAG=true)

DATA_DIR=$ORACLE_BASE/oradata
REDO_SIZE=200               # MB
MEMORY_PERCENT=40           # % of server memory for the database
# ==========================================

# Passwords: take them from the environment, or prompt (never hard-code them)
if [ -z "$SYS_PWD" ]; then
    read -s -p "SYS/SYSTEM password: " SYS_PWD; echo
fi
if [ "$CDB_FLAG" = true ] && [ -z "$PDBADMIN_PWD" ]; then
    read -s -p "PDBADMIN password: " PDBADMIN_PWD; echo
fi

if [ ! -x "$ORACLE_HOME/bin/dbca" ]; then
    echo "[ERROR] dbca not found in $ORACLE_HOME/bin"
    exit 1
fi

echo "============================================="
echo "   Oracle 19c Database Silent Creation"
echo "   SID      : $DB_SID"
echo "   DB Name  : $DB_NAME"
echo "   CDB Mode : $CDB_FLAG"
echo "============================================="

# Options common to both modes
COMMON_OPTS=(
    -silent -createDatabase
    -templateName General_Purpose.dbc
    -gdbName "$DB_NAME"
    -sid "$DB_SID"
    -responseFile NO_VALUE
    -characterSet AL32UTF8
    -sysPassword "$SYS_PWD"
    -systemPassword "$SYS_PWD"
    -databaseType MULTIPURPOSE
    -memoryPercentage "$MEMORY_PERCENT"
    -storageType FS
    -datafileDestination "$DATA_DIR"
    -redoLogFileSize "$REDO_SIZE"
    -emConfiguration NONE
)

if [ "$CDB_FLAG" = true ]; then
    echo "[INFO] Creating CDB with PDB $PDB_NAME ..."
    dbca "${COMMON_OPTS[@]}" \
        -createAsContainerDatabase true \
        -numberOfPDBs 1 \
        -pdbName "$PDB_NAME" \
        -pdbAdminPassword "$PDBADMIN_PWD"
else
    echo "[INFO] Creating non-CDB database ..."
    dbca "${COMMON_OPTS[@]}" \
        -createAsContainerDatabase false
fi
RC=$?

if [ $RC -eq 0 ]; then
    echo "[SUCCESS] Database $DB_NAME created successfully."
else
    echo "[ERROR] Database creation failed (rc=$RC). Check logs in $ORACLE_BASE/cfgtoollogs/dbca/$DB_NAME"
    exit 1
fi

Usage

Run as the oracle software owner:

BASH
chmod +x create_db.sh

# non-CDB called orcl19c (prompts for the password)
./create_db.sh

# CDB called cdb19c with PDB pdb1
./create_db.sh cdb19c true pdb1

# fully unattended: pass passwords through the environment
SYS_PWD='...' PDBADMIN_PWD='...' ./create_db.sh cdb19c true pdb1

What the Key Options Do

OptionMeaning
-templateName General_Purpose.dbcStart from Oracle's general-purpose template (includes pre-built data files, so creation is fast)
-createAsContainerDatabasetrue for a CDB, false for a non-CDB
-characterSet AL32UTF8Unicode — the recommended database character set
-memoryPercentage 40Give the database 40% of the server's RAM
-storageType FS -datafileDestinationData files on the file system under $ORACLE_BASE/oradata (use ASM and +DATA for ASM)
-redoLogFileSize 200200 MB online redo logs
-emConfiguration NONESkip EM Express setup

After It Finishes

BASH
grep orcl19c /etc/oratab          # DBCA adds the entry
. oraenv <<< orcl19c
sqlplus / as sysdba <<< "select name, open_mode, cdb from v\$database;"
Non-CDB architecture is deprecated in 19c and desupported from 21c onward, so for anything new, create a CDB (true). If you build a non-CDB now, see converting a non-CDB to a PDB.
