NOTE: Don’t start replicat until initial load is completed.

Till now we have configured on-going replication. It will  not capture the old data that is already existing on the table. For that we need to perform initial load.

We have so many methods to perform initial load. So of they are

Creating initial load extract

Performing datapump export and import

Using DMS

In this post am using initial load extract

Before that we need to create the table DDL’s on target database.

``` wp-block-code
CREATE TABLE Employees (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY,
    Name VARCHAR2(100) NOT NULL,
    Age NUMBER(3) CHECK (Age > 0),
    City VARCHAR2(100),
    Occupation VARCHAR2(100),
    PRIMARY KEY (ID)
);
```

Start the CDC replicat

After initial load and when I started CDC it got failed with unique constraint (HR.SYS_C007769) violated.  This is expected as we have started the change capture extract first and create the initial load. So some of the row which are captured In cdc are also captured by initial load due to which we got  voliation errors.

In order to handle collisions use HANDLECOLLISIONS parameter in replicate parameter file.

![](images/image-67.png)

And start the replicat
