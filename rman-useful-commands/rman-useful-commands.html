RMAN Useful Commands

By Sunke Nithin · April 16, 2025   DatabaseOracle

Oracle Recovery Manager (RMAN) is the tool for backing up, restoring and recovering Oracle databases. This is a quick-reference of the RMAN commands I use most for listing, checking and cleaning up backups. Run them from rman target /.

Reading "completed before". completed before 'sysdate-1' means older than 24 hours — it skips the last day's backups, not "today" by calendar date. Use completed after 'sysdate-1' for the last 24 hours.

Configuration

CommandWhat it does
show all;Shows every RMAN configuration setting (retention policy, channels, autobackup, …)

Listing Backups

CommandWhat it does
list backup;All backups: data files, control file, spfile and archived logs, in detail
list backup summary;The same as a one-line-per-backup table
list backup completed before 'sysdate-1';Backups older than 24 hours
list backup summary completed before 'sysdate-1';Summary of backups older than 24 hours
list backup of database;Database (data file) backups only
list backup of database summary completed before 'sysdate-1';Summary of database backups older than 24 hours
list backup tag 'TAG20230225T200006';Backups with a specific tag
list backup summary tag 'TAG20230225T200006';Summary for one tag
list backup tag like '%TAG2023022%';Tags matching a pattern
list backupset;All backup sets
list backupset summary;Summary of all backup sets
list backuppiece '/u01/backup/c-2972374659-20230301-00';One specific backup piece

Listing Backups of Specific Files

CommandWhat it does
list backup of datafile 1;Backups of data file 1
list backup of datafile 1,2 summary;Summary for several data files
list backup of tablespace system;Backups of a tablespace
list backup of tablespace system,sysaux summary;Summary for several tablespaces
list backup of controlfile;Control file backups
list backup of controlfile summary;Summary of control file backups
list backup of spfile;spfile backups
list backup of spfile summary;Summary of spfile backups

Archived Log Backups

CommandWhat it does
list backup of archivelog all;All archived log backups
list backup of archivelog all summary;Summary of all archived log backups
list backup of archivelog sequence 192;Backup of one log sequence
list backup of archivelog until sequence 192;Logs up to and including sequence 192
list backup of archivelog from sequence 186;Logs from sequence 186 onwards
list backup of archivelog sequence between 186 and 192;Logs in a range
list backup of archivelog sequence between 186 and 192 summary;The same range as a summary

Add thread N on RAC to pick a thread, e.g. list backup of archivelog sequence 192 thread 2;

Other Lists and Reports

CommandWhat it does
list incarnation;Database incarnations (one per OPEN RESETLOGS)
list restore point all;Restore points
list db_unique_name all;Databases registered under this DBID (Data Guard; needs a recovery catalog)
list copy;Image copies (data files, control file, archived logs)
report schema;Data files and temp files with tablespaces and sizes
report need backup;Files that need a backup to meet the retention policy
report obsolete;Backups no longer needed under the retention policy

Crosscheck

CommandWhat it does
crosscheck backup;Checks that every recorded backup piece still exists; marks missing ones EXPIRED
crosscheck backupset;The same, for backup sets
crosscheck backuppiece '/u01/backup/c-2972374659-20230225-04';One backup piece
crosscheck archivelog all;Checks archived logs on disk
crosscheck archivelog sequence 180;One log sequence
crosscheck archivelog sequence between 180 and 196;A range
crosscheck archivelog until sequence 196;Up to a sequence
crosscheck archivelog from sequence 180 until sequence 196;From one sequence to another
crosscheck copy;Image copies

Delete

CommandWhat it does
delete expired backup;Removes repository records for backups that crosscheck marked EXPIRED
delete obsolete;Deletes backups no longer needed under the retention policy
delete archivelog all;Deletes all archived logs (files and records) — asks first
delete noprompt archivelog all;The same without asking
delete archivelog sequence 180;One sequence
delete archivelog until sequence 190;Up to and including a sequence
delete archivelog from sequence 180 until sequence 190;A range
delete archivelog all backed up 1 times to device type disk;Only logs that already have a backup — the safe way to clean up
delete archivelog all completed before 'sysdate-2';Logs older than two days
delete archivelog all deletes logs whether or not they've been backed up (or applied on a standby). Set a deletion policy so RMAN refuses to delete logs that are still needed: CONFIGURE ARCHIVELOG DELETION POLICY TO BACKED UP 1 TIMES TO DISK; (or … APPLIED ON ALL STANDBY with Data Guard).

Catalog Existing Files

CommandWhat it does
catalog start with '/u01/backup/';Registers backup pieces and copies found under a directory — asks before cataloging
catalog start with '/u01/backup/' noprompt;The same without asking
catalog recovery area;Catalogs everything in the fast recovery area (same as catalog db_recovery_file_dest;)
catalog backuppiece '/u01/backup/piece1.bkp';One specific backup piece

Cataloging is how you make RMAN aware of backups copied in from another server, for example when building a standby or restoring to a new host.
