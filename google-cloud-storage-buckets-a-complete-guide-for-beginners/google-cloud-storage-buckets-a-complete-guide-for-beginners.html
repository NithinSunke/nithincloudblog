Google CLOUD Storage Buckets: A Complete Guide for Beginners

By Sunke Nithin · August 9, 2025   CLOUDGCP

Cloud Storage is Google CLOUD's object storage: a place for files of any size — backups, logs, images, data-lake files — with very high durability and pay-per-use pricing. Everything lives in buckets. This guide covers storage classes, locations, security, lifecycle rules and costs, and creating a bucket with the Console, gcloud and Terraform.

Buckets and Objects

  • A bucket is a container with a globally unique name, a location and a default storage class.
  • An object is a file plus metadata. The "folders" you see are just name prefixes (backups/2025/db.tar.gz).
  • Objects are immutable — changing one means uploading a new version.

Storage Classes

All classes have the same speed (millisecond access) and can be used in any location; they differ in storage price, retrieval charges and minimum storage duration.

ClassUse forMinimum durationRetrieval charge
StandardFrequently accessed ("hot") dataNoneNone
NearlineAccessed about once a month30 daysYes
ColdlineAccessed about once a quarter90 daysHigher
ArchiveAccessed less than once a year — long-term backup, compliance365 daysHighest

Deleting an object before its minimum duration is charged as if it had stayed. Autoclass can move objects between classes automatically based on access.

Choose region for lowest cost and latency next to your compute; dual- or multi-region for availability across a regional outage. The location can't be changed later.

Create a Bucket

Console

  1. Cloud Storage → Buckets → Create.
  2. A globally unique name (lowercase, numbers, dashes).
  3. Location type and location; default storage class.
  4. Access control: keep Enforce public access prevention on and choose Uniform access.
  5. Optional protection: versioning, retention policy.
  6. Create.

gcloud

BASH
gcloud storage buckets create gs://my-demo-bucket-123 \
  --location=us-central1 \
  --default-storage-class=STANDARD \
  --uniform-bucket-level-access \
  --public-access-prevention

Upload and list objects:

BASH
gcloud storage cp ./backup.tar.gz gs://my-demo-bucket-123/backups/
gcloud storage cp -r ./images gs://my-demo-bucket-123/
gcloud storage ls -l gs://my-demo-bucket-123/**

Terraform

HCL
resource "google_storage_bucket" "demo" {
  name                        = "my-demo-bucket-123"
  location                    = "US"
  storage_class               = "STANDARD"
  uniform_bucket_level_access = true
  public_access_prevention    = "enforced"
  force_destroy               = true      # lets terraform destroy delete a non-empty bucket - LAB only

  versioning { enabled = true }
}

Access Control

  • Use uniform bucket-level access (formerly called "Bucket Policy Only"): permissions come from IAM only, not per-object ACLs, which are hard to audit.
  • Keep public access prevention enforced unless the bucket really serves public content.
  • Grant the narrowest role — roles/storage.objectViewer to read, objectCreator to upload, objectAdmin to manage:
BASH
gcloud storage buckets add-iam-policy-binding gs://my-demo-bucket-123 \
  --member="user:john@example.com" \
  --role="roles/storage.objectViewer"

To share one file temporarily, use a signed URL:

BASH
# a link valid for 1 hour, without making the object public
gcloud storage sign-url gs://my-demo-bucket-123/backups/backup.tar.gz \
  --duration=1h --private-key-file=sa-key.json

Lifecycle Management

Move objects to Nearline after 30 days and delete them after a year:

LIFECYCLE.JSON
{
  "rule": [
    { "action": {"type": "SetStorageClass", "storageClass": "NEARLINE"},
      "condition": {"age": 30} },
    { "action": {"type": "Delete"},
      "condition": {"age": 365} }
  ]
}
BASH
gcloud storage buckets update gs://my-demo-bucket-123 --lifecycle-file=lifecycle.json
gcloud storage buckets describe gs://my-demo-bucket-123 --format="default(lifecycle_config)"

(The older gsutil lifecycle set lifecycle.json gs://bucket does the same; gsutil is being replaced by gcloud storage.)

Pricing in Brief

You pay for storage per GB-month (cheapest for Archive, most for Standard), for operations (uploads, listings), for retrieval from Nearline/Coldline/Archive, and for network egress out of Google CLOUD. Prices differ by location and change — check the Cloud Storage pricing page.

Best Practices

  • Uniform access and public access prevention on every bucket.
  • Versioning (with a lifecycle rule to expire old versions) for important data.
  • Lifecycle rules or Autoclass to control cost.
  • Signed URLs instead of public objects for temporary sharing.
  • Audit logs and Cloud Monitoring for access and usage.
