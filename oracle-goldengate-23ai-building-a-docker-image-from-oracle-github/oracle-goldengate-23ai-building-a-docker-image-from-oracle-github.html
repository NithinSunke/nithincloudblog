Oracle GoldenGate 23ai: Building a Docker Image from Oracle GitHub

By Sunke Nithin · April 28, 2025   ReplicationOracleGoldengateDocker

Oracle publishes official Dockerfiles for GoldenGate in its docker-images GitHub repository. You supply the GoldenGate software, the scripts build an Oracle Linux 8 image with GoldenGate 23ai Microservices and an nginx reverse proxy in front of it. Here's the build and a docker compose file to run it.

1Clone the Repository

BASH
git clone https://github.com/oracle/docker-images.git
cd docker-images/OracleGoldenGate/23

Each GoldenGate release has its own sub-folder (21, 23, …) — pick the one for your version. Read its README.md; it lists the build arguments and environment variables.

2Download GoldenGate 23ai

Oracle can't redistribute the binaries, so download Oracle GoldenGate 23ai for Oracle on Linux x86-64 yourself from Oracle Software Delivery Cloud or the GoldenGate downloads page, and copy the zip into the build directory. I renamed mine to oracle_gg_23ai.zip — the name doesn't matter, because you pass it to the build with INSTALLER.

4Run It with docker compose

Create a docker-compose.yml. I've removed the old version: line — Compose v2 ignores it and prints "version is obsolete":

YAML
services:
  goldengate:
    image: oracle/goldengate:23ai
    container_name: ogg23ai
    ports:
      - "880:80"      # HTTP  -> nginx reverse proxy
      - "4443:443"    # HTTPS -> nginx reverse proxy
    environment:
      - OGG_ADMIN=ggadmin
      - OGG_ADMIN_PWD=${OGG_ADMIN_PWD}   # read from .env, not hard-coded
      - OGG_DOMAIN=OGG23
      - OGG_DEPLOYMENT=OGG23ai
      - SSL_SKIP_CERT_VERIFY=true
    volumes:
      - ./u02:/u02                 # deployment (config, logs, checkpoints)
      - ./u03:/u03                 # trail files
      - ./cert:/etc/nginx/cert     # your own certificate (optional)
    restart: unless-stopped

Keep the admin password out of the compose file — put it in a .env file next to it, which Compose reads automatically (or use Docker secrets):

ENV
# .env  (same directory as docker-compose.yml; chmod 600)
OGG_ADMIN_PWD=<password>

The container starts the Service Manager and the deployment's Administration, Distribution, Receiver and Performance Metrics services. Wait for docker ps to show healthy, then log in with ggadmin.

Notes

  • Give the host enough resources — at least 4 GB of RAM for the container.
  • The deployment lives in the mounted volumes, so you can upgrade by building a new image and recreating the container.
  • Oracle also publishes a ready-made GoldenGate Free image on the Oracle Container Registry for learning and small workloads; check its licence terms — the image built here uses your licensed GoldenGate software.
