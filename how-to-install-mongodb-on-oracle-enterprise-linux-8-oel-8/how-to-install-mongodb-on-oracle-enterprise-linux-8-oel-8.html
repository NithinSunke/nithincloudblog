How to Install MongoDB on Oracle Enterprise Linux 8 (OEL 8)

By Sunke Nithin · August 22, 2025   DatabaseMongoDBLinux

MongoDB is a powerful, open-source NoSQL database known for its flexibility and scalability. Installing it on Oracle Enterprise Linux 8 (OEL 8) needs some care, because MongoDB supports only the Red Hat Compatible Kernel (RHCK) on Oracle Linux — not the Unbreakable Enterprise Kernel (UEK). This post walks step by step through installing MongoDB Community Edition 8.0 (the latest as of August 2025) on OEL 8, configuring it, and securing it.

Steps
  1. Verify the Kernel
  2. Create the MongoDB Repository
  3. Install MongoDB
  4. Start and Enable MongoDB
  5. Configure MongoDB (Optional)
  6. SELinux
  7. Verify the Installation

Notes, troubleshooting and uninstall

Prerequisites

  • Oracle Linux 8 (64-bit) booted with RHCK.
  • Administrative (root or sudo) privileges.
  • An internet connection for downloading packages.
  • Basic familiarity with Linux terminal commands.

1Verify the Kernel

MongoDB requires RHCK on Oracle Linux. Check which kernel you're running and switch if needed.

Check the current kernel

BASH
uname -r
Output containsKernelAction
el8 (e.g. 4.18.0-553.70.1.el8_10.x86_64)RHCKYou can proceed.
el8uekUEKSwitch to RHCK first (below).

List installed kernels

BASH
grubby --info=ALL | grep ^kernel

Identify a kernel with el8 but not uek (e.g. /boot/vmlinuz-4.18.0-553.70.1.el8_10.x86_64).

Switch to the RHCK kernel (if needed)

BASH
sudo grubby --set-default /boot/vmlinuz-<RHCK_kernel_version>
sudo reboot

Replace <RHCK_kernel_version> with the RHCK version, then reboot. Afterwards, uname -r should show the el8 kernel.

2Create the MongoDB Repository

MongoDB isn't in the default OEL 8 repositories, so add its official repository. Create the repository file:

BASH
sudo vi /etc/yum.repos.d/mongodb-org-8.0.repo

Add the following content, then save and exit:

/etc/yum.repos.d/mongodb-org-8.0.repo
[mongodb-org-8.0]
name=MongoDB Repository
baseurl=https://repo.mongodb.org/yum/redhat/$releasever/mongodb-org/8.0/x86_64/
gpgcheck=1
enabled=1
gpgkey=https://pgp.mongodb.com/server-8.0.asc

3Install MongoDB

Update the package list, then install MongoDB Community Edition with yum:

BASH
sudo yum update
sudo yum install -y mongodb-org

This installs the mongodb-org meta-package: the server (mongod), the shell (mongosh) and the database tools (mongodump, mongorestore and others). Accept the GPG key if prompted.

4Start and Enable MongoDB

MongoDB runs as a systemd service called mongod.

BASH
# Start the service
sudo systemctl start mongod

# Check it shows "active (running)"
sudo systemctl status mongod

# Start automatically on boot
sudo systemctl enable mongod

# Check the installed version
mongod --version

5Configure MongoDB (Optional)

By default MongoDB binds to 127.0.0.1 (localhost only), stores data in /var/lib/mongo and logs to /var/log/mongodb/mongod.log. To customize, edit the configuration file:

BASH
sudo vi /etc/mongod.conf

Example changes:

  • Change bindIp to 0.0.0.0 for remote access (and make sure the firewall allows port 27017).
  • Change dbPath or the log path for custom data and log directories.

Restart MongoDB after any change:

BASH
sudo systemctl restart mongod
Don't open bindIp: 0.0.0.0 to the network until you've enabled authentication in step 8 — until then, anyone who can reach port 27017 has full access.

6SELinux (Optional, for Compatibility)

SELinux in enforcing mode can stop mongod from starting or from using custom paths. The quick fix used in this lab is to set it to permissive.

BASH
# Check the current mode
getenforce

# Set permissive until the next reboot
sudo setenforce 0

# Make it permanent: change SELINUX=enforcing to SELINUX=permissive
sudo vi /etc/selinux/config
For production, MongoDB publishes an SELinux policy you can install instead, which keeps SELinux enforcing while allowing mongod to run. See the MongoDB Red Hat install guide.

7Verify the Installation

Connect to the MongoDB shell, check the version, and exit:

MONGOSH
mongosh          // opens the shell with a "test>" prompt
db.version()     // confirms the MongoDB version
exit

8Secure MongoDB (Recommended)

By default MongoDB allows connections without authentication. Create an admin user, then turn on authorization.

Create an admin user

MONGOSH
mongosh
use admin
db.createUser({
  user: "mongoadmin",
  pwd: passwordPrompt(),
  roles: [ { role: "userAdminAnyDatabase", db: "admin" }, "readWriteAnyDatabase" ]
})

Enter a secure password when prompted. passwordPrompt() keeps it out of your shell history.

Enable authentication

Edit /etc/mongod.conf:

BASH
sudo vi /etc/mongod.conf

Add or uncomment the security section, then save and exit:

/etc/mongod.conf
security:
  authorization: enabled

Restart and connect with authentication

BASH
sudo systemctl restart mongod
mongosh -u mongoadmin -p --authenticationDatabase admin
readWriteAnyDatabase and userAdminAnyDatabase cover reading, writing and user management, but not admin tasks such as dropping a database. For those, see Dropping a Database in MongoDB.

Notes

  • 64-bit only: MongoDB does not support 32-bit architectures.
  • Firewall: if connecting remotely, open port 27017:
BASH
sudo firewall-cmd --add-port=27017/tcp --permanent
sudo firewall-cmd --reload

Troubleshooting

ProblemWhat to check
No package mongodb-org availableThe repository file contents and the internet connection.
mongod.service fails to startThe log at /var/log/mongodb/mongod.log, that you're booted on RHCK (uname -r), and SELinux mode.

Uninstalling MongoDB

BASH
sudo yum erase $(rpm -qa | grep mongodb-org)
sudo rm -r /var/lib/mongo
sudo rm -r /var/log/mongodb
Removing /var/lib/mongo deletes all your databases permanently. Back up with mongodump first if you need the data.

Verification

After installation, MongoDB is running on port 27017 and you can start creating databases and collections — next, see Connecting to MongoDB on OEL 8. For further configuration or advanced setups (replica sets, sharding), see the MongoDB documentation.
