Steps to Create a Host-Only Network in Oracle VirtualBox from the Command Line on Windows

By Sunke Nithin · May 24, 2024   VirtualizationNetworkVirtualBox

A host-only network lets your VMs talk to each other and to the Windows host, without being exposed to the outside network — ideal for an Oracle or RAC lab. Here's how to create one and set its IP range with VBoxManage, no GUI needed.

create→list→set IP→attach to VM

0Open a Command Prompt in the VirtualBox Folder

VBoxManage isn't on the Windows PATH by default. Either change to the install folder or add it to PATH:

CMD
cd "C:\Program Files\Oracle\VirtualBox"

Creating host network adapters needs administrator rights, so run the Command Prompt as Administrator.

1Create the Host-Only Interface

CMD
VBoxManage hostonlyif create

Note the name it prints. If you already have a host-only adapter, the new one gets a suffix such as #2, and you'll use that name in the next steps.

2List the Host-Only Networks

CMD
VBoxManage list -l hostonlyifs

The new adapter gets a default address — 192.168.159.1/24 here.

3Set the IP Address and Netmask

Give the host side of the network the address you want — here 172.16.0.1/16:

CMD
VBoxManage hostonlyif ipconfig "VirtualBox Host-Only Ethernet Adapter" --ip 172.16.0.1 --netmask 255.255.0.0

The VirtualBox Network Manager (File → Tools → Network Manager) shows the same result:

4Attach a VM to the Network

With the VM powered off, connect one of its network adapters to the host-only network:

CMD
VBoxManage modifyvm "oel8-vm" --nic2 hostonly --hostonlyadapter2 "VirtualBox Host-Only Ethernet Adapter"

Replace oel8-vm with your VM's name. Inside the guest, give that interface a static address in the same range, for example 172.16.0.11/16. Keep a NAT adapter on nic1 if the VM also needs internet access.

Optional: Turn On DHCP

DHCP is disabled on the network above, so guests need static IPs — usually what you want in a database lab. To hand out addresses automatically instead:

CMD
VBoxManage dhcpserver add --interface="VirtualBox Host-Only Ethernet Adapter" --server-ip=172.16.0.2 --netmask=255.255.0.0 --lower-ip=172.16.0.100 --upper-ip=172.16.0.200 --enable

Quick Reference

TaskCommand
CreateVBoxManage hostonlyif create
ListVBoxManage list -l hostonlyifs
Set IPVBoxManage hostonlyif ipconfig "<name>" --ip <ip> --netmask <mask>
RemoveVBoxManage hostonlyif remove "<name>"
