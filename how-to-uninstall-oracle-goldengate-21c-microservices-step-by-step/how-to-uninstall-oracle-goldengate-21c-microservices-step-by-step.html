How to Uninstall Oracle GoldenGate 21c Microservices (Step-by-Step)

By Sunke Nithin · April 26, 2025   ReplicationOracleGoldengate

Removing GoldenGate 21c Microservices cleanly is three jobs: remove the deployment with the configuration assistant, remove the Service Manager service, and deinstall the software home. This undoes the setup from GoldenGate 21c Installation.

Before You Start

  • Identify the homes: software (OGG_HOME = /u01/app/oracle/ogg21c_ma1), Service Manager (ogg21c_sm1) and deployment (ogg21c_deploy1).
  • Back up what you might need later — parameter files, the credential store and wallets, configuration JSON in deployment/etc, and trail files:
BASH
tar czf /backup/orclgg01_$(date +%F).tgz \
    /u01/app/oracle/ogg21c_deploy1/etc \
    /u01/app/oracle/ogg21c_deploy1/var/lib/data      # trail files

Also clean up the database side if replication is being retired: unregister integrated extracts (UNREGISTER EXTRACT … DATABASE) and drop checkpoint and heartbeat tables, so you don't leave capture processes holding archive logs.

1Stop Processes and Services

Stop and delete Extracts, Replicats and distribution paths first:

ADMINCLIENT
[oracle@ggorcl01 bin]$ $OGG_HOME/bin/adminclient
OGG (not connected) 1> connect http://ggorcl01.scslabs.com:9100 deployment orclgg01 as ggadmin
OGG (http://ggorcl01.scslabs.com:9100 orclgg01) 2> info all
Program     Status      Group       Type             Lag at Chkpt  Time Since Chkpt
ADMINSRVR   RUNNING
DISTSRVR    RUNNING
PMSRVR      RUNNING
RECVSRVR    RUNNING

-- stop and remove any extracts, replicats and paths first, e.g.
OGG ... 3> stop extract *
OGG ... 4> stop replicat *

Then in the Service Manager web UI, select the deployment and stop each service:

2Remove the Deployment

BASH
cd $OGG_HOME/bin
./oggca.sh

Choose the existing Service Manager and Remove existing GoldenGate deployment:

Select the deployment, tick Delete deployment files from disk, enter the admin credentials, check the summary and finish:

To remove the Service Manager itself, run oggca.sh again once no deployments remain and remove the Service Manager deployment — or remove its service and directory as below.

3Remove the Service Manager Service

ROOT
# as root
systemctl stop OracleGoldenGate
systemctl disable OracleGoldenGate
rm -f /etc/systemd/system/OracleGoldenGate.service
systemctl daemon-reload

4Deinstall the Software Home

BASH
[oracle@ggorcl01 ~]$ cd /u01/app/oracle/ogg21c_ma1/deinstall/
[oracle@ggorcl01 deinstall]$ ./deinstall.sh

ALERT: Ensure all the processes running from the current Oracle Home are shutdown prior to running this software uninstallation script.

Proceed with removing Oracle GoldenGate home: /u01/app/oracle/ogg21c_ma1 (yes/no)? [no]
yes
...
Deinstall successful
Please check '/u01/app/oraInventory/logs/silentInstall2025-04-26_12-07-17PM.log' for more details.

5Verify and Clean Up

BASH
ps -ef | grep -i -E 'ServiceManager|adminsrvr|distsrvr|recvsrvr|pmsrvr' | grep -v grep
# remove the leftover Service Manager and deployment directories if you no longer need them
rm -rf /u01/app/oracle/ogg21c_sm1 /u01/app/oracle/ogg21c_deploy1

No GoldenGate processes should remain, and the home is gone from the central inventory.
