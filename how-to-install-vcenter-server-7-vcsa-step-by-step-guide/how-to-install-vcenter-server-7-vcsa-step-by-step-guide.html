How to Install vCenter Server 7 (VCSA) – Step-by-Step Guide

By Sunke Nithin · May 4, 2025   VirtualizationVmwareInstallation

After installing ESXi 7, the next step is vCenter Server — central management for hosts, VMs, templates and clusters. vCenter 7 is a Linux appliance (VCSA) deployed in two stages from an installer you run on your PC.

Prerequisites

  • A running ESXi 7 host with enough free resources (Tiny: 2 vCPUs, 12 GB RAM, ~415 GB thin-provisioned disk)
  • A static IP address for vCenter and DNS A and PTR records for its FQDN (here vcenter.scslabs.com → 192.168.1.101) — test forward and reverse lookups first; most failed installs are DNS problems
  • A Windows, Linux or macOS machine to run the installer
  • The vCenter Server 7 ISO (from the Broadcom support portal, formerly VMware Customer Connect)

4Log In

Open https://vcenter.scslabs.com → Launch vSphere Client and log in as administrator@<your SSO domain> — administrator@vsphere.local with the default domain, administrator@scslabs.com in my lab:

The appliance management interface is at https://vcenter.scslabs.com:5480 (log in as root).

Post-Installation

  • Create a datacenter and cluster, and add your ESXi hosts
  • Assign licences (vCenter runs in 60-day evaluation until then)
  • Configure HA, DRS and distributed switches as needed
  • Set up file-based backup of the appliance (VAMI → Backup)
  • Patch vCenter — 7.0 GA is old; apply the latest 7.0 update
