Steps to Install PostgreSQL on Oracle Linux 7

By Sunke Nithin · February 5, 2022   DatabasePostgresql

A quick install of PostgreSQL 12 on Oracle Linux 7 from the official PostgreSQL (PGDG) Yum repository: add the repo, install the server, initialise the cluster, start the service and connect with psql.

add PGDG repo→install server→initdb→enable & start→connect
Versions have moved on. This post was written in 2022. PostgreSQL 12 reached end of life in November 2024, and Oracle Linux 7 / RHEL 7 are past their standard support, so the PGDG repository no longer builds new PostgreSQL releases for EL7. For a new server, use Oracle Linux 8 or 9 and a current PostgreSQL version — the steps are the same; just pick your version and platform on the download page and swap 12 for the version number in the commands below.

1Pick the Version and Platform

Go to postgresql.org/download/linux/redhat and select the version, platform and architecture. The page generates the setup script for you.

Version 12 · EL7 · x86_64.

2Install the PGDG Repository

Run these as root (or with sudo):

BASH · ROOT
yum install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-7-x86_64/pgdg-redhat-repo-latest.noarch.rpm

3Install the PostgreSQL Server

BASH · ROOT
yum install -y postgresql12-server

Yum imports the PGDG signing key and installs the server along with the client and libraries:

PostgreSQL 12.9 server, client and libraries installed.

4Initialise the Database Cluster

BASH · ROOT
/usr/pgsql-12/bin/postgresql-12-setup initdb

This creates the data directory at /var/lib/pgsql/12/data, owned by the postgres OS user that the package created.

5Enable and Start the Service

BASH · ROOT
systemctl enable postgresql-12
systemctl start postgresql-12
systemctl status postgresql-12

The service is enabled at boot and running on port 5432.

6Connect and List the Databases

Switch to the postgres user and open psql:

BASH
su - postgres
psql

postgres=# \l

A fresh cluster has three databases: postgres, template0 and template1.

Set a password for the postgres database user while you're there, so you can log in over the network later:

SQL
\password postgres

7Optional: Allow Remote Connections

Out of the box PostgreSQL only listens on localhost (you can see 127.0.0.1 and ::1 in the status output). To reach it from other machines:

/VAR/LIB/PGSQL/12/DATA/POSTGRESQL.CONF
listen_addresses = '*'
/VAR/LIB/PGSQL/12/DATA/PG_HBA.CONF
# TYPE  DATABASE  USER  ADDRESS          METHOD
host    all       all   192.168.1.0/24   md5
BASH · ROOT
firewall-cmd --permanent --add-service=postgresql
firewall-cmd --reload
systemctl restart postgresql-12
Replace 192.168.1.0/24 with your own network. On PostgreSQL 14 and later, use scram-sha-256 instead of md5 — it's the default password method there.
