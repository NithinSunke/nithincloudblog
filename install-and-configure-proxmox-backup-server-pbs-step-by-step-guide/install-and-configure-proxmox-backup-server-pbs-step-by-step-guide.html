Install and Configure Proxmox Backup Server (PBS) — Step-by-Step Guide

By Sunke Nithin · April 22, 2025   VirtualizationProxmox

Proxmox Backup Server stores incremental, deduplicated, optionally encrypted backups of Proxmox VE virtual machines and containers. Here I install PBS 3.3 as a VM, create a datastore on a second disk, and add it to Proxmox VE as backup storage.

Prerequisites

  • A running Proxmox VE server
  • The PBS ISO from proxmox.com/downloads
  • A VM with at least 2 vCPUs, 2 GB RAM, a 32 GB system disk — and a separate disk for the backups
Running PBS as a VM on the same host it backs up is fine for learning, but a host failure takes the backups with it. In production, put PBS on separate hardware (or at least sync to a second PBS).

1Install PBS

Boot the VM from the ISO and choose Install Proxmox Backup Server (Graphical):

Accept the EULA and pick the target disk:

Set the country, time zone and keyboard, then the root password and an email address for notifications:

Configure the management network — hostname (FQDN), static IP, gateway and DNS — check the summary and click Install:

The VM reboots when the installation finishes.

2Open the Web UI

Browse to https://<PBS-IP>:8007 and log in as root (realm Linux PAM):

3Create a Datastore

Prepare the second disk and mount it permanently:

BASH
# on the PBS VM: second disk for backups
lsblk
fdisk /dev/sdb                 # create one partition: n, p, 1, Enter, Enter, w
mkfs.xfs /dev/sdb1
mkdir -p /mnt/pbsstore
echo '/dev/sdb1  /mnt/pbsstore  xfs  defaults  0 0' >> /etc/fstab
mount -a

Then in the PBS UI, Datastore → Add Datastore: name pbsstore, backing path /mnt/pbsstore, and schedules for garbage collection and pruning:

PBS can also create the file system for you: Administration → Storage / Disks → Directory → Create: Directory formats the disk, mounts it and adds the datastore in one step.

4Add PBS to Proxmox VE

PBS uses a self-signed certificate, so Proxmox VE needs its fingerprint. Copy it from the PBS dashboard (Show Fingerprint):

In the Proxmox VE web UI: Datacenter → Storage → Add → Proxmox Backup Server. Enter an ID, the PBS address, the user and password, the datastore name, and paste the fingerprint:

Use a dedicated account, not root@pam. Create a PBS user (or API token) with only the DatastoreBackup role on the datastore, and use that in Proxmox VE:
BASH
# on PBS: a dedicated user and API token for Proxmox VE
proxmox-backup-manager user create pve@pbs --password '<password>'
proxmox-backup-manager user generate-token pve@pbs pve
proxmox-backup-manager acl update /datastore/pbsstore DatastoreBackup --auth-id 'pve@pbs!pve'

In Proxmox VE, the username is then pve@pbs!pve and the "password" is the token secret.

5Back Up

  • Create backup jobs in Datacenter → Backup with pbs as storage.
  • In PBS, set Prune (retention), Garbage Collection and Verify jobs so space is reclaimed and backups are checked.
  • Consider client-side encryption (Encryption tab when adding the storage) — and keep the key somewhere safe.
  • Test a restore before you need one.
