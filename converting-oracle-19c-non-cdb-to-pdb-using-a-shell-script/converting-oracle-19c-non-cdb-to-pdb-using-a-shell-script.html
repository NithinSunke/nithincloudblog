Converting an Oracle 19c Non-CDB to a PDB with a Shell Script

By Sunke Nithin · August 18, 2025   DatabaseOracleScripts

Plugging a non-CDB into a container database follows a fixed sequence: describe it with DBMS_PDB.DESCRIBE, check compatibility, create the PDB from the XML file, run noncdb_to_pdb.sql, open it. This script does those steps on one server, stops at the first error, and logs everything.

What It Does

  1. Describe — restarts the non-CDB read only and writes its description to an XML file.
  2. Check — runs DBMS_PDB.CHECK_PLUG_COMPATIBILITY in the CDB; on failure, prints the open PDB_PLUG_IN_VIOLATIONS.
  3. Create — creates the PDB with COPY, so the original files stay untouched as a fallback.
  4. Convert and open — runs noncdb_to_pdb.sql inside the new PDB, then opens it and saves its state.
  5. Back up — an RMAN backup of the CDB.

Assumptions: 19c, both databases on the same server, a profile script per database, and room for a full copy of the data files.

The Script

NONCDB_TO_PDB.SH
#!/bin/bash
#######################################################################
# Script : noncdb_to_pdb.sh
# Purpose: Plug a 19c non-CDB into a CDB as a PDB (DBMS_PDB.DESCRIBE method)
# Author : Nithin Sunke
#######################################################################
set -o pipefail

NONCDB_PROFILE=/home/oracle/profile_ONCDB.sh     # sets ORACLE_SID=ONCDB etc.
CDB_PROFILE=/home/oracle/profile_O19TC.sh        # sets ORACLE_SID=O19TC etc.
PDB_NAME=ONCDB
XML_FILE=/home/oracle/noncdb.xml
SRC_DIR=/u02/oradata/ONCDB/
DST_DIR=/u02/oradata/O19TC/ONCDB/
LOG_FILE=/home/oracle/noncdb_to_pdb_$(date +%Y%m%d_%H%M%S).log

log() { echo "$(date '+%F %T') $*" | tee -a "$LOG_FILE"; }
die() { log "ERROR: $*"; echo "See $LOG_FILE"; exit 1; }

# run a block of SQL*Plus input; stop on any SQL or OS error
run_sql() {
  log "SQL> $(echo "$1" | head -1) ..."
  sqlplus -s / as sysdba >>"$LOG_FILE" 2>&1 <<EOF
WHENEVER SQLERROR EXIT SQL.SQLCODE
WHENEVER OSERROR EXIT FAILURE
SET SERVEROUTPUT ON FEEDBACK ON
$1
EXIT
EOF
  [ $? -eq 0 ] || die "SQL failed"
}

# ---- Step 1: describe the non-CDB
source "$NONCDB_PROFILE"
log "Step 1: generating $XML_FILE from $ORACLE_SID"
run_sql "SHUTDOWN IMMEDIATE
STARTUP MOUNT
ALTER DATABASE OPEN READ ONLY;
EXEC DBMS_PDB.DESCRIBE(pdb_descr_file => '$XML_FILE');
SHUTDOWN IMMEDIATE"
[ -s "$XML_FILE" ] || die "$XML_FILE was not created"

# ---- Step 2: compatibility check in the CDB
source "$CDB_PROFILE"
log "Step 2: checking plug compatibility in $ORACLE_SID"
RESULT=$(sqlplus -s / as sysdba <<EOF
SET SERVEROUTPUT ON FEEDBACK OFF HEADING OFF
DECLARE
  ok BOOLEAN;
BEGIN
  ok := DBMS_PDB.CHECK_PLUG_COMPATIBILITY(pdb_descr_file => '$XML_FILE', pdb_name => '$PDB_NAME');
  DBMS_OUTPUT.PUT_LINE(CASE WHEN ok THEN 'RESULT=YES' ELSE 'RESULT=NO' END);
END;
/
EXIT
EOF
)
echo "$RESULT" >>"$LOG_FILE"
if ! echo "$RESULT" | grep -q 'RESULT=YES'; then
  sqlplus -s / as sysdba >>"$LOG_FILE" <<'EOF'
SET LINES 200
COL message FOR a120
SELECT type, message FROM pdb_plug_in_violations WHERE status <> 'RESOLVED';
EOF
  die "not compatible - see PDB_PLUG_IN_VIOLATIONS in the log"
fi

# ---- Step 3: create the PDB (COPY keeps the original non-CDB intact)
mkdir -p "$DST_DIR"
log "Step 3: creating PDB $PDB_NAME"
run_sql "CREATE PLUGGABLE DATABASE $PDB_NAME USING '$XML_FILE'
  COPY FILE_NAME_CONVERT = ('$SRC_DIR', '$DST_DIR') TEMPFILE REUSE;"

# ---- Step 4: convert the data dictionary, then open
log "Step 4: running noncdb_to_pdb.sql (takes a while)"
run_sql "ALTER SESSION SET CONTAINER=$PDB_NAME;
@?/rdbms/admin/noncdb_to_pdb.sql"
run_sql "ALTER PLUGGABLE DATABASE $PDB_NAME OPEN;
ALTER PLUGGABLE DATABASE $PDB_NAME SAVE STATE;
SELECT name, open_mode, restricted FROM v\$pdbs;"
grep -q "$PDB_NAME.*READ WRITE.*NO" "$LOG_FILE" || die "$PDB_NAME is not open READ WRITE / unrestricted"

# ---- Step 5: back up the CDB
log "Step 5: RMAN backup"
rman target / >>"$LOG_FILE" 2>&1 <<'EOF' || die "RMAN backup failed"
BACKUP DATABASE PLUS ARCHIVELOG;
EOF

log "Done. Connect with:  sqlplus user/password@//$(hostname -f):1521/$PDB_NAME"
log "The original non-CDB is untouched (shut down). Drop it manually once you are satisfied."

Fixes Compared With My First Version

  • The old run_sql appended a / after every command, which re-executes the SQL buffer — it ran statements twice. Each block now carries its own terminators.
  • The compatibility check searched the log for COMPATIBLE, which also matches NOT COMPATIBLE, so it always passed. It now checks an explicit RESULT=YES.
  • noncdb_to_pdb.sql now runs before the PDB is opened read write, the order Oracle documents.
  • The PDB is named ONCDB, so the existing service name keeps working (it registers automatically — no tnsnames.ora edit needed on the server).
  • Dropping the old database is no longer part of the script; it needs STARTUP MOUNT EXCLUSIVE RESTRICT, and it's safer to do it by hand after testing:
SQL
# later, after testing - as the non-CDB's environment
sqlplus / as sysdba
STARTUP MOUNT EXCLUSIVE RESTRICT
DROP DATABASE;
Test on a copy first. Run it with nohup ./noncdb_to_pdb.sh & or in tmux — noncdb_to_pdb.sql can take a long time. Other methods: manual conversion · AutoUpgrade.
