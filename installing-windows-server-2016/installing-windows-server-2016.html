Installing Windows Server 2016

By Sunke Nithin · May 20, 2024   WindowsInstallation

A quick walkthrough of a clean Windows Server 2016 installation — physical or virtual — which I use as the base for the Windows lab servers on this blog.

Windows Server 2016 is in extended support until January 2027. For new servers, the steps for 2019, 2022 and 2025 are almost identical.

1Boot from the Installation Media

Attach the ISO to the virtual machine (or insert the DVD/USB on a physical server) and set it as the first boot device. The setup screen appears: choose the language, time and currency format and keyboard, then Next.

2Install Now

Click Install now. Enter a product key, or choose I don't have a product key for an evaluation install.

3Choose the Edition

OptionWhat you get
Standard / DatacenterServer Core — no graphical desktop, managed from the command line, PowerShell or remotely
Standard / Datacenter (Desktop Experience)The full GUI with Server Manager

For a lab where you'll use Server Manager and the MMC tools, choose a (Desktop Experience) option. You can't switch between Core and Desktop Experience later in 2016 without reinstalling.

4Accept the Licence Terms

Tick I accept the license terms → Next.

5Installation Type

Choose Custom: Install Windows only (advanced) for a new installation. (Upgrade is only for an existing Windows Server.)

6Choose the Disk

Select the disk (or unallocated space) and click Next. Setup creates the partitions it needs. On some hypervisors you may need to Load driver for the storage controller first (e.g. VirtIO on Proxmox/KVM).

7Let It Install

Setup copies files, installs features and updates, and restarts a couple of times. This takes 10–20 minutes.

8Set the Administrator Password

Enter a strong password for the built-in Administrator account and click Finish.

9Log In and First Steps

Press Ctrl+Alt+Del (in a VM console, use its "send Ctrl-Alt-Del" button) and sign in. Then, from Server Manager → Local Server:

  • Rename the computer and set a static IP address and DNS servers.
  • Set the time zone.
  • Run Windows Update until no updates remain.
  • Enable Remote Desktop if you'll manage it remotely.
  • Install the hypervisor's guest tools (VMware Tools, VirtIO guest agent).
