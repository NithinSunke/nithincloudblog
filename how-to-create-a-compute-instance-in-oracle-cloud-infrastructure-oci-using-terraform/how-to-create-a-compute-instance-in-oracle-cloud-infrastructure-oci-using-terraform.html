How to Create a Compute Instance in Oracle CLOUD Infrastructure (OCI) Using Terraform

By Sunke Nithin · April 14, 2025   CLOUDOCITerraform

This post provisions an Oracle Linux 8 VM in OCI with Terraform: a flexible shape, the newest platform image looked up automatically, no public IP, and your SSH key injected. It builds on the VCN created with Terraform.

Prerequisites

  • An OCI account and a user allowed to manage instances (see User, group and policy for Terraform)
  • OCI CLI configured (~/.oci/config) and Terraform 1.6+
  • The OCIDs of a compartment and a subnet, and an SSH key pair

1Provider — provider.tf

HCL
terraform {
  required_providers {
    oci = {
      source = "oracle/oci"
    }
  }
}

provider "oci" {
  region              = var.region
  config_file_profile = var.config_file_profile
}

2Variables — variables.tf and terraform.tfvars

HCL
variable "region"              { default = "us-phoenix-1" }
variable "config_file_profile" { default = "DEFAULT" }

variable "compartment_id" {
  description = "Compartment OCID for the instance"
  type        = string
}
variable "subnet_id" {
  description = "Subnet OCID for the primary VNIC"
  type        = string
}

variable "shape"         { default = "VM.Standard3.Flex" }
variable "ocpus"         { default = 2 }
variable "memory_in_gbs" { default = 8 }

variable "instance_name"       { default = "phoenix_instance" }
variable "vnic_hostname_label" { default = "phoenix-instance" }
variable "vnic_display_name"   { default = "phoenix_instance_vnic" }

variable "ssh_public_key_path" {
  description = "Path to your SSH public key"
  type        = string
  default     = "~/.ssh/id_rsa.pub"     # e.g. C:/Users/<you>/.ssh/oci_key.pub on Windows
}
HCL
# terraform.tfvars  (keep OCIDs out of variables.tf)
compartment_id = "ocid1.compartment.oc1..<your-compartment>"
subnet_id      = "ocid1.subnet.oc1.phx.<your-private-subnet>"

3Image Lookup and Instance — main.tf

HCL
# first availability domain of the region (names are tenancy-specific, e.g. "kWcK:PHX-AD-1")
data "oci_identity_availability_domains" "ads" {
  compartment_id = var.compartment_id
}

# newest Oracle Linux 8 platform image that supports the chosen shape
data "oci_core_images" "latest_ol8_image" {
  compartment_id           = var.compartment_id
  operating_system         = "Oracle Linux"
  operating_system_version = "8"
  shape                    = var.shape
  sort_by                  = "TIMECREATED"
  sort_order               = "DESC"
}

resource "oci_core_instance" "phoenix_instance" {
  availability_domain = data.oci_identity_availability_domains.ads.availability_domains[0].name
  compartment_id      = var.compartment_id
  display_name        = var.instance_name
  shape               = var.shape

  shape_config {
    ocpus         = var.ocpus
    memory_in_gbs = var.memory_in_gbs
  }

  create_vnic_details {
    subnet_id        = var.subnet_id
    assign_public_ip = false
    display_name     = var.vnic_display_name
    hostname_label   = var.vnic_hostname_label
  }

  source_details {
    source_type             = "image"
    source_id               = data.oci_core_images.latest_ol8_image.images[0].id
    boot_volume_size_in_gbs = 50
  }

  metadata = {
    ssh_authorized_keys = file(pathexpand(var.ssh_public_key_path))
  }
}

output "image_ocid" { value = data.oci_core_images.latest_ol8_image.images[0].id }
output "private_ip" { value = oci_core_instance.phoenix_instance.private_ip }
  • The image data source filters on var.shape, so changing the shape can't pick an incompatible image.
  • The availability domain is looked up instead of hard-coded — AD names carry a tenancy-specific prefix.
  • assign_public_ip = false: reach the VM through a bastion, VPN or the private network. Set it to true (on a public subnet) if you need direct SSH.

4Deploy

BASH
terraform init
terraform fmt
terraform validate
terraform plan -out tfplan
terraform apply tfplan

Saving the plan with -out guarantees that apply does exactly what you reviewed. Connect with ssh -i <private key> opc@<private_ip>.

5Clean Up

BASH
terraform destroy
