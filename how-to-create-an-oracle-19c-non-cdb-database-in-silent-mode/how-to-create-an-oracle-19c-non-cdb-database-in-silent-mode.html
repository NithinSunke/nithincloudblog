How to Create an Oracle 19c Non-CDB Database in Silent Mode

By Sunke Nithin · August 16, 2025   DatabaseOracle

DBCA in silent mode creates a database with a single command — no GUI, no X server, and the same result every time. That makes it the right tool for scripts and automation. Here I create a 19c non-CDB database called ONCDB.

Prerequisites

  1. Oracle Database 19c software installed (for example a cloned home)
  2. The environment set for that home:
BASH
export ORACLE_BASE=/u01/app/oracle
export ORACLE_HOME=/u01/app/oracle/product/19.0.0/dbhome_2
export PATH=$ORACLE_HOME/bin:$PATH
  1. A listener running from the home (create one with netca -silent -responseFile $ORACLE_HOME/assistants/netca/netca.rsp) so DBCA can register the database.
  2. The data file directory (/u02/oradata) created and owned by oracle.

Create the Database

BASH
dbca -silent -createDatabase \
   -templateName General_Purpose.dbc \
   -gdbName ONCDB \
   -sid ONCDB \
   -createAsContainerDatabase false \
   -characterSet AL32UTF8 \
   -nationalCharacterSet AL16UTF16 \
   -sysPassword '<sys_password>' \
   -systemPassword '<system_password>' \
   -databaseType MULTIPURPOSE \
   -memoryPercentage 40 \
   -storageType FS \
   -datafileDestination /u02/oradata \
   -redoLogFileSize 200 \
   -emConfiguration NONE

Put the real passwords in place of the placeholders — or leave the two password options out and DBCA prompts for them, which keeps them out of your shell history.

What the Key Options Do

OptionMeaning
-gdbName / -sidGlobal database name and instance name (ONCDB)
-createAsContainerDatabase falseNon-CDB. Use true plus -numberOfPDBs / -pdbName for a CDB
-templateName General_Purpose.dbcSeed template with pre-built data files — the fastest option
-memoryPercentage 40SGA + PGA = 40% of server RAM
-storageType FS / -datafileDestinationFiles on a filesystem; use ASM with -diskGroupName +DATA for ASM
-redoLogFileSize 200Redo log size in MB
-emConfiguration NONENo EM Express configuration

Other useful options — initialization parameters, archive log mode and a recovery area:

BASH
   -initParams "processes=500,open_cursors=500,db_recovery_file_dest=/u02/fra,db_recovery_file_dest_size=20G" \
   -enableArchive true \
   -archiveLogDest /u02/arch

Verify

BASH
export ORACLE_SID=ONCDB
sqlplus / as sysdba <<'EOF'
select name, cdb, open_mode, log_mode from v$database;
select value from nls_database_parameters where parameter='NLS_CHARACTERSET';
EOF
grep ONCDB /etc/oratab
Non-CDB is deprecated. 19c is the last release that supports non-CDB databases; 21c and later are CDB-only. Create non-CDBs only when an application or upgrade path needs one.
