Install Oracle Database 11.2.0.4 on Oracle Linux 7

By Sunke Nithin · June 13, 2019   DatabaseOracleInstallation

How I installed the Oracle Database 11g Release 2 (11.2.0.4) software on Oracle Linux 7 — preinstall RPM, directories, the installer, and the root scripts.

11.2.0.4 is long out of support (extended support ended in 2020; only Market Driven Support remains). Use it only to practise upgrades or to mirror a legacy system. For anything new, install 19c.

1Install Oracle Linux 7

See Oracle Linux 7 Installation.

2Download the Software

11.2.0.4 is a full release delivered as patch 13390677 on My Oracle Support. It has seven zips, but a database install needs only the first two:

3Install the Preinstall RPM

It installs the required packages, creates the oracle user and groups, and sets kernel parameters and limits:

BASH
[root@oradbdvl01 ~]# yum install -y oracle-rdbms-server-11gR2-preinstall

4OS Settings

Set SELinux to permissive (or disabled) in /etc/selinux/config, and make sure the server's own hostname resolves:

BASH
sed -i 's/^SELINUX=.*/SELINUX=permissive/' /etc/selinux/config
setenforce 0
HOSTS
# /etc/hosts — the server's own name must resolve

5Directories, Software and the oracle Password

BASH
mkdir -p /a01/oracle /a01/oraInventory /soft/db
cd /soft/db
unzip -q p13390677_112040_Linux-x86-64_1of7.zip
unzip -q p13390677_112040_Linux-x86-64_2of7.zip
chown -R oracle:oinstall /a01 /soft/db
passwd oracle

6Run the Installer

Log in as oracle in a graphical session (VNC or X forwarding) and run /soft/db/database/runInstaller:

  1. Untick "I wish to receive security updates" and confirm you don't want to give an email address.
  2. Skip software updates.
  3. Install database software only → Single instance database installation.
  4. Language English → Enterprise Edition.
  5. Oracle base /a01/oracle, software location /a01/oracle/11.2.0/db.
  6. Inventory directory /a01/oraInventory, group oinstall.
  7. Privileged groups: OSDBA dba, OSOPER oper (or dba).
  8. Prerequisite checks — fix any failures before continuing (on OL7 some checks report missing packages that are actually installed; ignoring those is fine).
  9. Review the summary and Install.
Known OL7 issue: linking fails with "Error in invoking target 'agent nmhs' of makefile ins_emagent.mk". Edit $ORACLE_HOME/sysman/lib/ins_emagent.mk, change $(MK_EMAGENT_NMECTL) to $(MK_EMAGENT_NMECTL) -lnnz11, and click Retry (MOS Doc ID 1965691.1).
