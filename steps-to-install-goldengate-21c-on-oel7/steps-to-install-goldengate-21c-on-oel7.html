Steps to Install Oracle GoldenGate 21c Microservices on Oracle Linux 7

By Sunke Nithin · June 22, 2024   ReplicationOracleGoldengate

In this post we install Oracle GoldenGate 21c Microservices Architecture (21.3) on Oracle Linux 7: install the software with the Oracle Universal Installer, then create a Service Manager and a deployment with the configuration assistant (oggca.sh), register the Service Manager as a system service, and log in to the web consoles.

unzip→runInstaller→orainstRoot.sh→oggca.sh→registerServiceManager.sh→web console

0Assumptions

  • Oracle Linux 7 is installed, with an oracle user in the oinstall group.
  • The GoldenGate 21c Microservices for Oracle software is downloaded from Oracle Software Delivery Cloud or My Oracle Support.
  • An X display is available for the oracle user (VNC, MobaXterm or X11 forwarding) — both the installer and oggca.sh are GUIs.
GoldenGate 21c was the current release when this was written. For new installs, use the latest GoldenGate release on a supported OS — see Steps to Install Oracle GoldenGate 23ai for the newer installer and configuration screens. Whatever the release, apply the latest GoldenGate bundle patch after installing.

1Copy and Unzip the Software

BASH · ORACLE
cd /u01/soft/
ls
213000_fbo_ggs_Linux_x64_Oracle_services_shiphome.zip

unzip 213000_fbo_ggs_Linux_x64_Oracle_services_shiphome.zip

The zip extracts the installer, a README and the release notes:

2Install the GoldenGate Software

BASH · ORACLE
cd /u01/soft/fbo_ggs_Linux_x64_Oracle_services_shiphome/Disk1/
./runInstaller

Walk through the wizard: choose the option for Oracle Database 21c and lower, set the software location to /u01/app/ogg/gg_home, and — on a host's first Oracle install — set the inventory to /u01/app/oraInventory with group oinstall.

The Install Wizard, from installation option to the root script prompt.

When prompted, run the inventory script as root, then click OK to finish:

BASH · ROOT
/u01/app/oraInventory/orainstRoot.sh

3Create the Service Manager and Deployment

Run the configuration assistant from the GoldenGate home:

BASH · ORACLE
cd /u01/app/ogg/gg_home/bin
./oggca.sh

The wizard has 12 steps. The key choices:

StepSetting
Service Manager optionsCreate new Service Manager at /u01/app/ogg/ogg_sm, host ogg.scslabs.com, port 7000, register as a system service/daemon
Configuration optionsAdd new GoldenGate deployment
Deployment detailsName prodogg, software home /u01/app/ogg/gg_home
Deployment directoriesDeployment home /u01/app/ogg/ogg_deploy (sub-directories filled in automatically)
Environment variablesOGG_HOME, LD_LIBRARY_PATH, TNS_ADMIN (defaults)
Administrator accountggadmin with a strong password
Security optionsSSL/TLS off (lab only)
Port settings7001–7005, monitoring enabled, BDB datastore
Replication settingsDefault schema C##GGADMIN

oggca.sh steps 1–10.

Lab vs production: I left SSL/TLS off to keep the lab simple, so the consoles run over plain HTTP. For anything beyond a lab, enable security with certificates — GoldenGate then serves the consoles over HTTPS.

Register the Service Manager as a service

Click Finish. Part way through, the assistant asks you to run a script as root so the Service Manager starts at boot:

BASH · ROOT
/u01/app/ogg/ogg_sm/bin/registerServiceManager.sh

If you'll reach the consoles from another machine, open the ports in the firewall:

BASH · ROOT
firewall-cmd --permanent --add-port=7000-7005/tcp
firewall-cmd --reload

5Log In to the Web Consoles

The Service Manager runs on port 7000 — http://192.168.1.11:7000. Log in as ggadmin; it lists the four prodogg services, all running:

The Administration Service on port 7001 is where you create Extracts and Replicats:

Scripting it: both tools can run without the GUI. Save the response files from the Summary screens, then use ./runInstaller -silent -responseFile /path/oggcore.rsp and ./oggca.sh -silent -responseFile /path/oggca.rsp for repeatable installs.
