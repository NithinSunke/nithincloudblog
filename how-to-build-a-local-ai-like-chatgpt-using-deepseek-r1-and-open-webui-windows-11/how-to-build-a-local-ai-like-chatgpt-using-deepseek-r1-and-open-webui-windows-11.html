How to Build a Local AI like ChatGPT Using DeepSeek-R1 and Open WebUI (Windows 11)

By Sunke Nithin · April 8, 2025   AILAB

You can run a ChatGPT-style assistant entirely on your own PC: Ollama downloads and runs the model, DeepSeek-R1 is the model, and Open WebUI gives it a browser chat interface. Nothing you type leaves your machine.

The Pieces

  • DeepSeek-R1 — an open-weight reasoning model from DeepSeek. The small sizes (1.5b–14b) are versions distilled onto Qwen and Llama bases; the 8b used here needs about 5 GB of disk and runs on a recent CPU, faster with a GPU.
  • Ollama — a runtime that pulls models and serves them on http://localhost:11434. Available for Windows, macOS and Linux.
  • Open WebUI — a self-hosted web front end that talks to Ollama. It's a Python application, so it runs on any OS (or in Docker); Windows 11 is simply what I used.
Browser → Open WebUI (:8080) → Ollama API (:11434) → deepseek-r1:8b

1Install Ollama

Download the Windows installer from ollama.com and run it — no options to choose.

2Pull and Test DeepSeek-R1

Browse the model list at ollama.com/search, then in PowerShell:

POWERSHELL
ollama --version
ollama run deepseek-r1:8b        # downloads the model on first use, then opens a chat prompt
                                  # type /bye to leave
ollama list                      # models stored locally
ollama ps                        # models loaded in memory right now

Pick a size that fits your memory: roughly the model's file size in free RAM (or GPU VRAM) plus a couple of GB.

3Install and Start Open WebUI

The Open WebUI documentation recommends running it with uv, which creates an isolated Python environment for it automatically. Set DATA_DIR so your users and chats are kept in one folder between upgrades:

POWERSHELL
# 1. install uv (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# 2. run Open WebUI, keeping its data in a fixed folder
$env:DATA_DIR="C:\open-webui\data"; uvx --python 3.11 open-webui@latest serve

The first start downloads some embedding models, then the server listens on port 8080.

4Open the Web Interface

Browse to http://localhost:8080 (or the PC's IP, http://192.168.1.10:8080 in my LAB). The first account you create becomes the administrator. Open WebUI finds the local Ollama automatically — choose deepseek-r1:8b at the top and start chatting.

Open WebUI listens on all interfaces, so anyone on your network can reach the sign-up page. Create your admin account straight away, and keep new sign-ups disabled or pending (Admin Panel → Settings → General). Don't expose port 8080 to the internet.

Other Ways to Install Open WebUI

POWERSHELL
# pip (Python 3.11 in a virtual environment)
py -3.11 -m venv C:\open-webui\venv
C:\open-webui\venv\Scripts\activate
pip install open-webui
open-webui serve

# Docker Desktop
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway ^
  -v open-webui:/app/backend/data --name open-webui --restart always ^
  ghcr.io/open-webui/open-webui:main

With Docker the UI is at http://localhost:3000 and reaches Ollama on the host through host.docker.internal.

What Next

Inside Open WebUI you can upload documents and chat with them, create custom model presets with your own system prompt, and add more models with ollama pull. To ground the model in your own PDFs, see Use DeepSeek-R1 with Your PDF Articles in Ollama.

Installation commands follow the Open WebUI documentation.
