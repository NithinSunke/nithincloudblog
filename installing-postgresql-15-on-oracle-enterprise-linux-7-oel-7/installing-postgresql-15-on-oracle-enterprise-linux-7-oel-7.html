Installing PostgreSQL 15 on Oracle Linux 7

By Sunke Nithin · August 16, 2025   DatabasePostgresql

Installing PostgreSQL 15 on Oracle Linux 7 from the official PostgreSQL (PGDG) yum repository: add the repo, install the server, initialise a cluster, and start it as a service.

OL7 is end of life for PGDG. The PostgreSQL project no longer builds new packages for EL7, so the EL7 repository is frozen at the last release of each version (15.14 here). It's fine for a lab; for anything new use Oracle Linux 8 or 9, where the same steps work with dnf.

Prerequisites

  • Oracle Linux 7 (minimal or server)
  • root or sudo access
  • Internet access to download.postgresql.org
BASH
sudo yum update -y

1Add the PostgreSQL Repository

BASH
sudo yum install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-7-x86_64/pgdg-redhat-repo-latest.noarch.rpm

The repo RPM defines repositories for several PostgreSQL versions; you pick the version by package name.

2Install PostgreSQL 15

BASH
sudo yum install -y postgresql15-server

3Initialise the Database and Start the Service

BASH
sudo /usr/pgsql-15/bin/postgresql-15-setup initdb
sudo systemctl enable --now postgresql-15
sudo systemctl status postgresql-15

The data directory is /var/lib/pgsql/15/data.

4First Steps

BASH
# connect as the postgres OS user
sudo -iu postgres psql -c "select version();"

# set a password for the postgres role
sudo -iu postgres psql -c "\password postgres"

# allow remote connections (optional)
sudo vi /var/lib/pgsql/15/data/postgresql.conf     # listen_addresses = '*'
sudo vi /var/lib/pgsql/15/data/pg_hba.conf         # host all all 192.168.1.0/24 scram-sha-256
sudo systemctl restart postgresql-15
sudo firewall-cmd --permanent --add-service=postgresql && sudo firewall-cmd --reload
