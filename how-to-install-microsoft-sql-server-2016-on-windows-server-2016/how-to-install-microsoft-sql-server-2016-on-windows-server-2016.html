How to Install Microsoft SQL Server 2016 on Windows Server 2016

By Sunke Nithin · April 11, 2025   DatabaseMSSQLInstallation

A complete SQL Server 2016 (SP2) Evaluation install on Windows Server 2016: download the media, run setup, configure the instance, then install SQL Server Management Studio (SSMS) and create a first database. This was the source server for my SQL Server-to-Oracle migration posts.

SQL Server 2016 is in extended support until July 2026. For new work use a current version; the installer looks almost the same.

Prerequisites

  • Windows Server 2016, fully patched
  • Administrator rights
  • Separate disks for data, logs and TempDB (recommended)

1Download

Search for "SQL Server 2016 download" and use the Microsoft Evaluation Center (180-day evaluation). Download the small EXE bootstrapper:

The bootstrapper offers Basic, Custom or Download Media. I downloaded the media so I could run the full setup (and reuse it):

2Run Setup

Run setup.exe from the media. In the SQL Server Installation Center choose Installation → New SQL Server stand-alone installation:

Product Key — leave Evaluation (or choose the free Developer edition for a non-production lab). Accept the licence terms:

Global Rules pass; skip or use Microsoft Update; setup files are installed:

3Features and Instance

Select Database Engine Services (plus anything else you need) and keep the default directories, then name the instance. I used a named instance, SQLDB:

4Server and Database Engine Configuration

Service accounts — the defaults are virtual accounts; in production use a dedicated domain (or managed service) account per service. Set the Agent to start automatically if you'll use jobs:

Authentication — I chose Mixed Mode with an sa password (needed later for the SQL Developer connection) and added the current user as administrator. Data directories and TempDB — put data, logs and TempDB on separate disks for performance:

The default TempDB size of 8 MB is tiny. Pre-size the TempDB files (equal sizes, one file per core up to 8) to what your workload needs.

Click Install and wait for it to complete:

5Install SQL Server Management Studio

SSMS is a separate download — Install SQL Server Management Tools in the Installation Center links to it:

SSMS 20 needs .NET Framework 4.7.2 or later; Windows Server 2016 ships with 4.6, so setup fails:

Download and install the .NET Framework 4.8 offline installer, then reboot:

Now SSMS installs:

6Create a Database

Connect SSMS to .\SQLDB, right-click Databases → New Database, give it a name and click OK:

Best Practices

  • Apply the latest service pack and cumulative update.
  • For remote connections, enable TCP/IP in SQL Server Configuration Manager, set a fixed port for named instances (or run SQL Server Browser), open the firewall, and restart the service.
  • Set max server memory so Windows keeps enough RAM.
  • Schedule backups — and test restores.
  • Evaluation and Developer editions are for testing only; license production use.
