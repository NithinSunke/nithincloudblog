How to Create a Linux Virtual Machine (VM) in Proxmox VE

By Sunke Nithin · April 22, 2025   VirtualizationProxmox

With Proxmox VE installed, the first real task is usually a Linux VM. This walk-through creates an Oracle Linux 8 VM through the Create VM wizard; the same steps work for Ubuntu, Debian, Rocky and the rest.

Prerequisites

  • A running Proxmox VE host
  • A Linux ISO uploaded to an ISO-capable storage
  • A VM storage — here the vmdata thin pool from Add Storage Disks to Proxmox VE

1Upload the ISO

Download the ISO from the distribution's site, then in the GUI: (your node) → local → ISO Images → Upload. You can also use Download from URL to let the host fetch it directly.

2General

Click Create VM (top right). Pick the node, keep or set the VM ID, and give it a name — oel8 here. Tick Advanced at the bottom to see every option.

3OS

Select the ISO, Guest OS type Linux, version 6.x – 2.6 Kernel.

4System

Defaults are fine: SeaBIOS, machine i440fx, SCSI controller VirtIO SCSI single. Tick Qemu Agent if you'll install the guest agent (recommended). For UEFI choose OVMF and add an EFI disk.

5Disks

Bus SCSI, storage vmdata, 50 GiB, IO thread on. On thin or SSD storage tick Discard so space freed in the guest is returned to the pool.

6CPU

1 socket, 2 cores. The default type x86-64-v2-AES keeps live migration between different CPUs possible; host gives the best performance on a single host.

7Memory

8192 MiB here. With Ballooning Device on, a lower Minimum memory lets Proxmox reclaim RAM from the guest when the host is under pressure.

8Network

Bridge vmbr0, model VirtIO (paravirtualized).

9Confirm

Review and click Finish (or tick Start after created).

10Start and Install

Select the VM, click Start, open Console and run the installer as usual.

After installation, add the guest agent so Proxmox can see the IP address and shut the VM down cleanly:

BASH
# inside the guest after installation
sudo dnf install -y qemu-guest-agent      # apt install qemu-guest-agent on Ubuntu/Debian
sudo systemctl enable --now qemu-guest-agent
# then: VM → Options → QEMU Guest Agent → Enabled, and restart the VM

Convert to a Template (Optional)

To reuse this VM as a base image, shut it down and choose Convert to template. Clean it first — see Cloud-Init in Proxmox VE for the steps.
