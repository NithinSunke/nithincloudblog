This task installs Windows Server 2022; the screenshots in later tasks come from Windows Server 2016. The steps in this series are the same on 2016, 2019 and 2022.

Installing Windows Server 2022 on Proxmox VE gives you the best of both worlds: a modern Windows OS and a powerful open-source hypervisor. Whether you’re setting up a homelab or evaluating enterprise solutions, this guide walks you through the full process.

What You’ll Need

Before you begin, make sure you have the following:

  • Proxmox VE (v6.4 or newer recommended)
  • Windows Server 2022 ISO (Evaluation or Licensed)
  • VirtIO Drivers ISO (for Windows to recognize Proxmox hardware) Download here

Step-by-Step Installation

Step 1: Upload ISO Files to Proxmox

Step 2: Create the Virtual Machine

Add a second CD/DVD drive with the VirtIO drivers ISO, so Windows Setup can load the disk and network drivers.

Step 3: Start the VM and Begin Installation

When Setup shows no disks, click Load driver, browse the VirtIO CD to the storage driver folder for your Windows version, and install it. The disk then appears.

Step 4: Install the QEMU Guest Agent

  1. Mount the VirtIO ISO inside the guest.
  2. Run guest-agent\qemu-ga-x86_64.msi from the VirtIO CD.
  3. In Proxmox, enable Options → QEMU Guest Agent for the VM. The agent enables graceful shutdown, IP reporting, and better integration with Proxmox.

Final Thoughts

Running Windows Server on Proxmox is a great way to combine the reliability of Linux with the functionality of Windows. Whether you're running a lab, test environment, or production workload, this setup gives you flexibility, performance, and control.
