Steps to Install Oracle Database 23ai Free on Oracle Linux 8

By Sunke Nithin · June 4, 2024   DatabaseOracleInstallation

Oracle Database 23ai Free is a full-featured, no-cost edition of Oracle Database for developing, learning and small workloads. In this post we install it on Oracle Linux 8 from the RPM, fix the one error I hit on the way, create the database and connect with SQL*Plus.

download RPM→dnf install→configure→set environment→connect
Name change: since this post was written, Oracle has renamed 23ai to Oracle AI Database 26ai, and the free edition is now Oracle AI Database Free. The install still follows the same pattern — download the RPM for your Oracle Linux version from the Free quick-start page, dnf install it, then run the configure script it prints — but the package, script and Oracle home names change, so use the ones shown on the download page.

0Assumptions

  • Oracle Linux 8 is installed.
  • The OS is updated to the latest packages (dnf update -y).
  • The machine can reach the Oracle Linux yum repositories, so dnf can pull in the dependencies.
Free edition limitValue
CPU2 threads
Memory (SGA + PGA)2 GB
User data12 GB

1Download the RPM

From the Oracle Database Free get-started page, pick the Oracle Linux 8 RPM. The page also lists the two commands you'll run:

You can download it straight onto the server:

BASH · ROOT
wget https://download.oracle.com/otn-pub/otn_software/db-free/oracle-database-free-23ai-1.0-1.el8.x86_64.rpm
The RPM is about 1.3 GB and installs to roughly 3.6 GB under /opt/oracle, so make sure that file system has room.

2Install the RPM

BASH · ROOT
dnf install -y oracle-database-free*

dnf pulls in 31 dependencies, including oracle-database-preinstall-23ai, which creates the oracle user and groups and sets the kernel parameters and limits.

4Set the Environment and Connect

As the oracle user, create a small profile file:

PROFILE.FREE
export ORACLE_SID=FREE
export ORACLE_HOME=/opt/oracle/product/23ai/dbhomeFree
export ORAENV_ASK=NO
export PATH=$ORACLE_HOME/bin:$PATH
alias ss='sqlplus / as sysdba'

Source it and connect:

BASH
