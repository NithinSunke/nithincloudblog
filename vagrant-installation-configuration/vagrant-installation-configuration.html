Vagrant Installation & Configuration

By Sunke Nithin · May 20, 2024   Automationvagrant

Vagrant builds and manages reproducible virtual machines from a single configuration file, which makes it a quick way to spin up lab servers. This post covers installing Vagrant on Windows, verifying it, and the basic workflow: add a box, create a VM, connect to it, and tear it down.

Prerequisites

  • A Windows machine with administrator rights.
  • A virtualization provider for Vagrant to drive — most commonly Oracle VirtualBox. Install it before running vagrant up.

1Download Vagrant

Download the Windows installer from the official page: developer.hashicorp.com/vagrant/install (the older vagrantup.com/downloads address redirects there).

2Install Vagrant on Windows

Run the downloaded .msi and work through the setup wizard:

  1. On the welcome screen, click Next.
  2. Accept the license agreement and click Next.
  3. Keep the default destination folder (or choose another) and click Next.
  4. Click Install and approve the Windows administrator prompt.
  5. Click Finish, and restart Windows when the installer asks — Vagrant is added to your PATH during the install.

3Verify Vagrant

Open a new Command Prompt or PowerShell window and check the installation:

SHELL
vagrant --version
vagrant --help

vagrant --version prints the installed version; vagrant --help lists the available commands.

4Basic Workflow in Vagrant

box add→init→up→ssh→halt→destroy

Create a working folder for your VMs:

SHELL
mkdir vagrant-vms
cd vagrant-vms

Add a box (a base VM image) under a local name, then list your boxes:

SHELL
vagrant box add centos-min https://github.com/tommy-muehle/puppet-vagrant-boxes/releases/download/1.1.0/centos-7.0-x86_64.box
vagrant box --help
vagrant box list
CentOS 7 reached end of life in June 2024 and this box is no longer maintained. For a current lab, add a maintained box from HashiCorp's box catalog instead — for example vagrant box add bento/oraclelinux-8 — and use that name in vagrant init.

Create a Vagrantfile for the box, start the VM, and connect to it:

SHELL
vagrant init centos-min   # writes a Vagrantfile in the current folder
vagrant up                # creates and boots the VM
vagrant ssh               # opens an SSH session into the VM

When you're done, stop or remove the VM:

SHELL
vagrant halt              # shuts the VM down (keeps it)
vagrant destroy           # deletes the VM entirely

Command reference

CommandWhat it does
vagrant box add <name> <url>Downloads a box and stores it under a local name.
vagrant box listLists the boxes installed on this machine.
vagrant init <box>Creates a Vagrantfile that uses the box.
vagrant upCreates and starts the VM described by the Vagrantfile.
vagrant sshOpens an SSH session into the running VM.
vagrant haltGracefully shuts the VM down.
vagrant destroyStops and deletes the VM and its disks (the box stays installed).
Run these commands from the folder that contains the Vagrantfile — Vagrant uses that file to know which VM you mean.
