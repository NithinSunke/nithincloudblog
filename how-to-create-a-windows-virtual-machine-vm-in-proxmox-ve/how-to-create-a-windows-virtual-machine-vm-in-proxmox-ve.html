How to Create a Windows Virtual Machine (VM) in Proxmox VE

By Sunke Nithin · April 22, 2025   VirtualizationProxmox

Proxmox VE runs Windows guests well, as long as you give them the VirtIO drivers for the paravirtualized disk and network. This guide builds a Windows 10 VM with UEFI, VirtIO SCSI and VirtIO networking.

Prerequisites

  • A running Proxmox VE host
  • A Windows ISO (10/11 or Server)
  • The VirtIO drivers ISO from the Fedora project: virtio-win (stable)

1Upload Both ISOs

(your node) → local → ISO Images → Upload — the Windows ISO and virtio-win-x.y.z.iso.

2General

Click Create VM, pick the node, VM ID and a name (windows10).

3OS

Select the Windows ISO, type Microsoft Windows and the version. Tick Add additional drive for VirtIO drivers and pick the virtio-win ISO — the wizard attaches it as a second CD drive.

4System

Machine q35, BIOS OVMF (UEFI), SCSI controller VirtIO SCSI single, and tick Qemu Agent.

Tick "Add EFI Disk" when you choose OVMF (it's unticked in my screenshot). Without an EFI disk the UEFI settings and boot entries are not saved and can be lost on the next start. For Windows 11 also tick Add TPM (v2.0) — setup refuses to continue without TPM 2.0 and Secure Boot.

5Disks

Bus SCSI on the VirtIO SCSI controller, 50 GiB on vmdata, IO thread on; tick Discard on thin/SSD storage. Leave cache at Default (No cache) — Write back is faster but can lose data on a host crash.

6CPU

1 socket, 2 cores or more. Type x86-64-v2-AES (default) or host for the best performance.

7Memory

About 8 GB here; 4 GB is the practical minimum for Windows 10/11.

8Network

Bridge vmbr0, model VirtIO (paravirtualized). Windows has no built-in driver for it — it's installed in step 10.

9Confirm

10Install Windows and Load the Storage Driver

Start the VM and open the Console (press a key when it says Press any key to boot from CD). When setup asks Where do you want to install Windows? and shows no disk:

  1. Click Load driver → Browse.
  2. On the virtio-win CD open vioscsi → w10 → amd64 (pick the folder matching your Windows version, e.g. w11, 2k22).
  3. Load the Red Hat VirtIO SCSI pass-through controller driver; the disk appears.
The driver folder must match the disk bus: vioscsi for SCSI on a VirtIO SCSI controller (as here), viostor if you chose the VirtIO Block bus.

11Post-Installation

  • Run virtio-win-guest-tools.exe from the root of the virtio-win CD. It installs every remaining driver — NetKVM (network), Balloon, serial, display — and the QEMU Guest Agent in one go.
  • Check Device Manager for any device still without a driver.
  • Install Windows updates, enable Remote Desktop if needed, then remove the two ISOs from Hardware.
