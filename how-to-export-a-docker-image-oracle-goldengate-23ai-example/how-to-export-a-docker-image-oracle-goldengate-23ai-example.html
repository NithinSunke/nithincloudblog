How to Export a Docker Image: Oracle GoldenGate 23ai Example

By Sunke Nithin · April 28, 2025   DockerDockerGoldengate

After building an Oracle GoldenGate 23ai image you don't want to repeat the build on every host. docker save writes the image to a file you can copy, archive or load elsewhere — no Docker Hub needed.

1Identify the Image

BASH
docker images oracle/goldengate
OUTPUT
REPOSITORY          TAG    IMAGE ID       CREATED         SIZE
oracle/goldengate   23ai   c3b2d7ab9ab4   5 minutes ago   7.3GB

2Save the Image to a File

BASH
docker save -o goldengate23ai.tar oracle/goldengate:23ai

# or save and compress in one step
docker save oracle/goldengate:23ai | gzip > goldengate23ai.tar.gz

The archive contains every layer, the tags and the metadata. Images compress well, so the gzip version is usually much smaller.

docker save vs docker export: save works on an image and keeps its layers, tags, environment and entrypoint. export works on a container and produces a flat filesystem without that metadata — not what you want for moving an image.

3Move the File

Copy it with scp/rsync, put it in object storage (OCI, S3) or on a NAS:

BASH
scp goldengate23ai.tar.gz oracle@target-host:/u01/images/
sha256sum goldengate23ai.tar.gz        # compare on both sides

4Load It on the Target

BASH
docker load -i goldengate23ai.tar.gz   # .tar or .tar.gz both work
docker images oracle/goldengate

The image appears with its original name and tag, ready for docker run.

Alternative: a Private Registry

BASH
# simple private registry on the LAB network
docker run -d -p 5000:5000 --restart always --name registry registry:2

docker tag oracle/goldengate:23ai myregistry.local:5000/oracle/goldengate:23ai
docker push myregistry.local:5000/oracle/goldengate:23ai

# on another host
docker pull myregistry.local:5000/oracle/goldengate:23ai
This registry has no TLS, so each Docker host must list it under "insecure-registries": ["myregistry.local:5000"] in /etc/docker/daemon.json. For anything beyond a LAB, put TLS and authentication in front of it — and remember Oracle images are licensed software; keep them in private storage.
