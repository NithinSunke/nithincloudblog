How to Install VMware ESXi 7: Step-by-Step Guide for Beginners

By Sunke Nithin · May 4, 2025   VirtualizationVmwareInstallation

VMware ESXi is a bare-metal hypervisor: it installs directly on the server and runs virtual machines. Here's a complete ESXi 7.0 installation — installer, management network, web client, licence and a datastore.

Prerequisites

  • A server with a supported 64-bit CPU and Intel VT-x/AMD-V enabled in the BIOS
  • At least 2 CPU cores and 8 GB RAM (4 GB is the bare minimum to install; you need more to run VMs)
  • A boot device of at least 32 GB (SSD recommended — ESXi 7 no longer recommends SD cards or small USB sticks as boot media)
  • The ESXi 7 ISO (Broadcom support portal) and a USB stick for the installer, written with Rufus or balenaEtcher
  • A static IP, hostname and DNS server for the host
Check the compatibility guide — consumer NICs and storage controllers often lack ESXi drivers. Note also that Broadcom ended the free ESXi licence in 2024; the 60-day evaluation still works for a lab.
