Oracle Data Guard Configuration Shell Script

By Sunke Nithin · July 9, 2019   DatabaseScripts

A bash script that builds a physical standby database end to end from the primary server: it checks ARCHIVELOG and FORCE LOGGING, sets the Data Guard parameters, configures the standby listener and TNS entries over ssh, creates standby redo logs, runs RMAN DUPLICATE … FOR STANDBY FROM ACTIVE DATABASE, and starts managed recovery. It was written for 11.2.0.4 but works the same on 12c–19c (non-CDB).

What the Script Does

StepWhat happens
1Checks it runs as oracle and isn't already running (run-flag file)
2Logs in to the primary as SYSDBA to test the credentials
3Enables ARCHIVELOG mode and FORCE LOGGING if needed (asks first — ARCHIVELOG needs a restart)
4Sets LOG_ARCHIVE_CONFIG, LOG_ARCHIVE_DEST_2 (deferred), FAL_SERVER and STANDBY_FILE_MANAGEMENT on the primary
5Creates the data file and FRA directories on the standby
6Writes a listener.ora with a static entry for the standby, copies it over and starts the listener
7Adds TNS entries for both databases on both servers and tnspings them from each side
8Adds standby redo logs on the primary, copies the password file, and starts the standby in NOMOUNT with a one-line pfile
9Runs the RMAN active duplicate from the primary
10Starts managed recovery with real-time apply, enables redo transport, switches a log
11Scans its log for ORA-/RMAN- errors, removes old logs, and emails the result

Prerequisites

BASH
# on the primary, as oracle: passwordless ssh to the standby
ssh-keygen -t rsa
ssh-copy-id oracle@orclstdy01.snv.ind
ssh oracle@orclstdy01.snv.ind hostname

# on the standby: Oracle software installed in the same ORACLE_HOME path,
# and an oratab entry so oraenv works
echo "sunkdev:/a01/oracle/11.2.0.4/db:N" >> /etc/oratab
  • Oracle software installed on the standby at the same ORACLE_HOME path, and the same directory layout (the script uses NOFILENAMECHECK).
  • Port 1521 open between the servers, and mailx configured if you want the emails.
  • Edit the variables at the top: database names, host names, paths and redo log size (match your online redo logs).

Usage

BASH
chmod 700 build_standby.sh
./build_standby.sh

The script stops and asks before each change to the primary. Don't leave the SYS password in the file — replace the DBA_PASSWORD line with read -rsp "SYS password: " DBA_PASSWORD, or use a wallet.

BASH
#!/bin/bash
# +----------------------------------------------------------------------------+
# | build_standby.sh                                                           |
# | Creates a physical standby with RMAN active duplicate (Oracle 11.2+).     |
# | Run on the PRIMARY server as the oracle OS user.                           |
# +----------------------------------------------------------------------------+

export ORACLE_SID=sunkdev
ORAENV_ASK=NO
. oraenv
ORAENV_ASK=YES

# +----------------------------------------------------------------------------+
# | GLOBAL VARIABLES                                                           |
# +----------------------------------------------------------------------------+
SCRIPT_NAME_FULL=$0
SCRIPT_NAME=${SCRIPT_NAME_FULL##*/}
SCRIPT_NAME_NOEXT=${SCRIPT_NAME%%.sh}

# ---- primary / standby ----
PRIMARY_DB_NAME=sunkdev          # db_unique_name and TNS alias of the primary
STANDBY_DB_NAME=sunksbdev        # db_unique_name and TNS alias of the standby
DBA_USERNAME=SYS
DBA_PASSWORD='<sys_password>'    # better: read -s, or a wallet (see the post)
PRIMARY_HOST_NAME=oradbdvl01.snv.ind
STANDBY_HOST_NAME=orclstdy01.snv.ind
STANDBY_SSH=oracle@${STANDBY_HOST_NAME}
STANDBY_ORACLE_HOME=/a01/oracle/11.2.0.4/db   # same path as the primary home
STANDBY_STAGE_DIR=/c01/standby                # scratch directory on the standby
DATAFILE_DIR=/a01/oracle/oradata/${PRIMARY_DB_NAME}
FRA_DIR=/a01/oracle/fast_recovery_area
REDO_SIZE=50M                                 # must match the online redo log size

# ---- directories ----
ORACLE_BASE=/a01/oracle
CUSTOM_ORACLE_DIR=/d01/scripts
CUSTOM_ORACLE_LOG_DIR=${CUSTOM_ORACLE_DIR}/log
CUSTOM_ORACLE_TEMP_DIR=${CUSTOM_ORACLE_DIR}/temp

# ---- host / date ----
HOSTNAME=$(hostname)
HOSTNAME_SHORT=${HOSTNAME%%.*}
HOSTNAME_SHORT_UPPER=$(echo "$HOSTNAME_SHORT" | tr '[:lower:]' '[:upper:]')
START_DATE=$(date)
DATE_LOG=$(date +%Y-%m-%d-%H%M%S)

# ---- email ----
ORGANIZATION_NAME="Example"
MAIL_RECIPIENT_LIST_EXIT_SUCCESS="dba@example.com"
MAIL_RECIPIENT_LIST_EXIT_FAILED="dba@example.com"
MAIL_FROM="${ORGANIZATION_NAME} Database Support <dba@example.com>"

# ---- log / temp files ----
LOG_FILE_NAME=${CUSTOM_ORACLE_LOG_DIR}/${SCRIPT_NAME_NOEXT}_${HOSTNAME_SHORT_UPPER}_${DATE_LOG}.log
LOG_FILE_NAME_NODATE=${CUSTOM_ORACLE_LOG_DIR}/${SCRIPT_NAME_NOEXT}_${HOSTNAME_SHORT_UPPER}.log
LOG_FILE_ARCHIVE_OBSOLETE_DAYS=8
CHECK_SCRIPT_RUNNING_FLAG_FILE=${CUSTOM_ORACLE_TEMP_DIR}/${SCRIPT_NAME_NOEXT}_${HOSTNAME_SHORT_UPPER}.running
SQL_OUTPUT_TEMP_FILE_NAME=${CUSTOM_ORACLE_TEMP_DIR}/${SCRIPT_NAME_NOEXT}_${HOSTNAME_SHORT_UPPER}.lst

HOST_RVAL_SUCCESS=0
HOST_RVAL_FAILED=1
HIDE_PASSWORD_STRING="xxxxxxxxxxxxx"

mkdir -p "$CUSTOM_ORACLE_LOG_DIR" "$CUSTOM_ORACLE_TEMP_DIR"

# +----------------------------------------------------------------------------+
# | COMMON FUNCTIONS                                                           |
# +----------------------------------------------------------------------------+
function wl {
  echo "${1}" >> "${LOG_FILE_NAME}"
  echo "${1}"
}

function banner {
  wl " "
  wl "+-------------------------------------------------------------------------+"
  wl "| $(date '+%m/%d/%Y %H:%M:%S')  ${1}"
  wl "+-------------------------------------------------------------------------+"
}

function askYesNo {             # askYesNo "question" -> exits on n / empty
  wl "${1} (y/[n]):"
  read -r userResponse
  if [[ -z ${userResponse} || ${userResponse} == [Nn] ]]; then
    wl "Exiting script as per user request. Good-bye!"
    removeScriptRunFlagFile
    exit ${HOST_RVAL_SUCCESS}
  fi
}

function removeScriptRunFlagFile {
  rm -f "${CHECK_SCRIPT_RUNNING_FLAG_FILE}"
  wl "TRACE> Removed script run flag file (${CHECK_SCRIPT_RUNNING_FLAG_FILE})"
}

function sendEmail {            # sendEmail SEVERITY "addr1 addr2"
  local L_SEVERITY=${1}
  local L_EMAIL_ADDRESS
  local SUBJECT="[${HOSTNAME_SHORT_UPPER}] - ${L_SEVERITY}: ${SCRIPT_NAME}"
  for L_EMAIL_ADDRESS in ${2}; do
    echo "See the attached log." | mailx -s "${SUBJECT}" -r "${MAIL_FROM}" -a "${LOG_FILE_NAME}" "${L_EMAIL_ADDRESS}"
    wl "TRACE> Sent email to ${L_EMAIL_ADDRESS}"
  done
}

function finish {               # finish SUCCESSFUL|FAILED|RUNNING
  local L_SEVERITY=${1}
  wl " "
  wl "TRACE> ${L_SEVERITY}"
  [[ ${L_SEVERITY} != "RUNNING" ]] && removeScriptRunFlagFile
  wl "FINISH TIME: $(date)"
  cp -f "${LOG_FILE_NAME}" "${LOG_FILE_NAME_NODATE}"
  if [[ ${L_SEVERITY} == "SUCCESSFUL" ]]; then
    sendEmail "SUCCESSFUL" "${MAIL_RECIPIENT_LIST_EXIT_SUCCESS}"
    exit ${HOST_RVAL_SUCCESS}
  else
    sendEmail "FAILED" "${MAIL_RECIPIENT_LIST_EXIT_FAILED}"
    exit ${HOST_RVAL_FAILED}
  fi
}

function checkScriptAlreadyRunning {
  if [ -f "${CHECK_SCRIPT_RUNNING_FLAG_FILE}" ]; then
    wl "TRACE> WARNING: ${SCRIPT_NAME} is already running on this host. Exiting."
    finish "RUNNING"
  fi
  touch "${CHECK_SCRIPT_RUNNING_FLAG_FILE}"
}

function verifyOSUserLogin {
  local L_UID
  L_UID=$(id -un)
  if [[ ${L_UID} != "oracle" ]]; then
    wl "TRACE> Logged in as (${L_UID}). Run this script as the oracle OS user."
    finish "FAILED"
  fi
}

function verifyTNSConnectString {
  wl "TRACE> tnsping ${1}"
  if ! "$ORACLE_HOME/bin/tnsping" "${1}" >> "${LOG_FILE_NAME}"; then
    wl "TRACE> The TNS service name (${1}) IS NOT valid."
    finish "FAILED"
  fi
  wl "TRACE> The TNS service name (${1}) IS valid."
}

function verifyDatabaseLoginCredentials {   # db user password SYSDBA|""
  local L_DB_NAME=${1} L_USER=${2} L_PWD=${3} L_PRIV=""
  [[ ${4} == "SYSDBA" ]] && L_PRIV=" AS SYSDBA"
  wl "TRACE> Test login (${L_USER}/${HIDE_PASSWORD_STRING}@${L_DB_NAME}${L_PRIV})."
  "$ORACLE_HOME/bin/sqlplus" -s /nolog > "${SQL_OUTPUT_TEMP_FILE_NAME}" <<EOF
WHENEVER OSERROR EXIT 9
WHENEVER SQLERROR EXIT SQL.SQLCODE
CONNECT ${L_USER}/"${L_PWD}"@${L_DB_NAME}${L_PRIV}
SET HEAD OFF
SELECT 'Logged in as ' || lower(user) FROM dual;
EOF
  if grep -qE 'ORA-|PLS-|SP2-' "${SQL_OUTPUT_TEMP_FILE_NAME}"; then
    cat "${SQL_OUTPUT_TEMP_FILE_NAME}" | tee -a "${LOG_FILE_NAME}"
    wl "TRACE> Database credentials for (${L_DB_NAME}${L_PRIV}) ARE NOT valid."
    finish "FAILED"
  fi
  wl "TRACE> Database credentials for (${L_DB_NAME}${L_PRIV}) are valid."
  rm -f "${SQL_OUTPUT_TEMP_FILE_NAME}"
}

function runSql {               # runSql <<'EOF' ... EOF   (local, as sysdba)
  sqlplus -s / as sysdba | tee -a "${LOG_FILE_NAME}"
}

function sqlValue {             # sqlValue "select ..." -> single value
  sqlplus -s / as sysdba <<EOF | tr -d '[:space:]'
set head off feedback off pagesize 0
$1
EOF
}

# +----------------------------------------------------------------------------+
# | DATA GUARD FUNCTIONS                                                       |
# +----------------------------------------------------------------------------+
function archiveLogging {
  local L_MODE
  L_MODE=$(sqlValue 'select log_mode from v$database;')
  if [[ ${L_MODE} == "ARCHIVELOG" ]]; then
    wl "Database is in ARCHIVELOG mode."
    return
  fi
  wl "Database is in NOARCHIVELOG mode."
  askYesNo "Enable ARCHIVELOG mode? This restarts the primary database"
  runSql <<'EOF'
shutdown immediate
startup mount
alter database archivelog;
alter database open;
EOF
  wl "Database is now in $(sqlValue 'select log_mode from v$database;') mode."
}

function forceLogging {
  if [[ $(sqlValue 'select force_logging from v$database;') == "YES" ]]; then
    wl "FORCE LOGGING is enabled."
    return
  fi
  wl "FORCE LOGGING is NOT enabled."
  askYesNo "Enable FORCE LOGGING on the primary database?"
  echo 'ALTER DATABASE FORCE LOGGING;' | runSql
}

function initializationParams {
  cat > "${CUSTOM_ORACLE_TEMP_DIR}/primary_config.sql" <<EOF
ALTER SYSTEM SET LOG_ARCHIVE_CONFIG='DG_CONFIG=(${PRIMARY_DB_NAME},${STANDBY_DB_NAME})' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_2='SERVICE=${STANDBY_DB_NAME} ASYNC NOAFFIRM VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=${STANDBY_DB_NAME}' SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE_2=DEFER SCOPE=BOTH;
ALTER SYSTEM SET FAL_SERVER=${STANDBY_DB_NAME} SCOPE=BOTH;
ALTER SYSTEM SET STANDBY_FILE_MANAGEMENT=AUTO SCOPE=BOTH;
ALTER SYSTEM SET REMOTE_LOGIN_PASSWORDFILE=EXCLUSIVE SCOPE=SPFILE;
EOF
  cat "${CUSTOM_ORACLE_TEMP_DIR}/primary_config.sql" | tee -a "${LOG_FILE_NAME}"
  askYesNo "Apply the parameters above to the primary database?"
  echo "@${CUSTOM_ORACLE_TEMP_DIR}/primary_config.sql" | runSql
}

function standbyDirectories {
  ssh "${STANDBY_SSH}" "mkdir -p ${DATAFILE_DIR} ${FRA_DIR}/${STANDBY_DB_NAME^^} ${STANDBY_STAGE_DIR} ${ORACLE_BASE}/admin/${PRIMARY_DB_NAME}/adump" | tee -a "${LOG_FILE_NAME}"
}

function standbyListener {
  # static registration so RMAN can connect to the NOMOUNT auxiliary instance
  cat > "${CUSTOM_ORACLE_TEMP_DIR}/listener.ora" <<EOF
SID_LIST_LISTENER =
  (SID_LIST =
    (SID_DESC =
      (GLOBAL_DBNAME = ${STANDBY_DB_NAME})
      (ORACLE_HOME = ${STANDBY_ORACLE_HOME})
      (SID_NAME = ${ORACLE_SID})
    )
  )

LISTENER =
  (DESCRIPTION_LIST =
    (DESCRIPTION = (ADDRESS = (PROTOCOL = TCP)(HOST = ${STANDBY_HOST_NAME})(PORT = 1521)))
    (DESCRIPTION = (ADDRESS = (PROTOCOL = IPC)(KEY = EXTPROC1521)))
  )

ADR_BASE_LISTENER = ${ORACLE_BASE}
EOF
  cat "${CUSTOM_ORACLE_TEMP_DIR}/listener.ora" | tee -a "${LOG_FILE_NAME}"
  scp -p "${CUSTOM_ORACLE_TEMP_DIR}/listener.ora" "${STANDBY_SSH}:${STANDBY_STAGE_DIR}/"
  ssh "${STANDBY_SSH}" bash -s <<EOF | tee -a "${LOG_FILE_NAME}"
cp ${STANDBY_STAGE_DIR}/listener.ora ${STANDBY_ORACLE_HOME}/network/admin/listener.ora
export ORACLE_HOME=${STANDBY_ORACLE_HOME}
\$ORACLE_HOME/bin/lsnrctl stop  >/dev/null 2>&1
\$ORACLE_HOME/bin/lsnrctl start
EOF
}

function tnsEntries {
  cat > "${CUSTOM_ORACLE_TEMP_DIR}/tnsnames.ora" <<EOF
${PRIMARY_DB_NAME} =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = ${PRIMARY_HOST_NAME})(PORT = 1521))
    (CONNECT_DATA = (SERVICE_NAME = ${PRIMARY_DB_NAME}))
  )

${STANDBY_DB_NAME} =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = ${STANDBY_HOST_NAME})(PORT = 1521))
    (CONNECT_DATA = (SERVICE_NAME = ${STANDBY_DB_NAME})(UR = A))
  )
EOF
  cat "${CUSTOM_ORACLE_TEMP_DIR}/tnsnames.ora" | tee -a "${LOG_FILE_NAME}"
  # append only if the aliases are not there yet, so a re-run does not duplicate them
  grep -qi "^${STANDBY_DB_NAME} *=" "$ORACLE_HOME/network/admin/tnsnames.ora" 2>/dev/null || \
    cat "${CUSTOM_ORACLE_TEMP_DIR}/tnsnames.ora" >> "$ORACLE_HOME/network/admin/tnsnames.ora"
  # passwordless ssh is required: https://oracle-base.com/articles/linux/user-equivalence-configuration-on-linux
  scp -p "${CUSTOM_ORACLE_TEMP_DIR}/tnsnames.ora" "${STANDBY_SSH}:${STANDBY_STAGE_DIR}/"
  ssh "${STANDBY_SSH}" bash -s <<EOF | tee -a "${LOG_FILE_NAME}"
F=${STANDBY_ORACLE_HOME}/network/admin/tnsnames.ora
grep -qi "^${STANDBY_DB_NAME} *=" \$F 2>/dev/null || cat ${STANDBY_STAGE_DIR}/tnsnames.ora >> \$F
EOF
}

function verifyTnsFromStandby {
  # quoted heredoc: \$? and the if-tests run on the STANDBY, not locally
  ssh "${STANDBY_SSH}" PRI="${PRIMARY_DB_NAME}" STB="${STANDBY_DB_NAME}" OH="${STANDBY_ORACLE_HOME}" bash -s <<'EOF' | tee -a "${LOG_FILE_NAME}"
rc=0
for alias in "$PRI" "$STB"; do
  if "$OH/bin/tnsping" "$alias" >/dev/null; then
    echo "TRACE> (standby) TNS alias $alias IS valid"
  else
    echo "TRACE> (standby) TNS alias $alias IS NOT valid"; rc=1
  fi
done
exit $rc
EOF
  if (( PIPESTATUS[0] != 0 )); then
    finish "FAILED"
  fi
}

function copyPasswordFile {
  # the standby needs the primary's password file (same SYS password) for redo transport
  scp -p "$ORACLE_HOME/dbs/orapw${ORACLE_SID}" "${STANDBY_SSH}:${STANDBY_ORACLE_HOME}/dbs/orapw${ORACLE_SID}"
  wl "TRACE> Copied password file orapw${ORACLE_SID} to the standby."
}

function standbyRedo {
  # standby redo logs: same size as the online logs, one more group than the online logs.
  # Created on the primary so they exist after a switchover; RMAN duplicate creates them on the standby too.
  askYesNo "Create standby redo logs on the primary?"
  runSql <<EOF
ALTER DATABASE ADD STANDBY LOGFILE ('${DATAFILE_DIR}/stdby_redo01.log') SIZE ${REDO_SIZE};
ALTER DATABASE ADD STANDBY LOGFILE ('${DATAFILE_DIR}/stdby_redo02.log') SIZE ${REDO_SIZE};
ALTER DATABASE ADD STANDBY LOGFILE ('${DATAFILE_DIR}/stdby_redo03.log') SIZE ${REDO_SIZE};
ALTER DATABASE ADD STANDBY LOGFILE ('${DATAFILE_DIR}/stdby_redo04.log') SIZE ${REDO_SIZE};
EOF
}

function standbyPfile {
  echo "db_name=${PRIMARY_DB_NAME}" > "${CUSTOM_ORACLE_TEMP_DIR}/init${ORACLE_SID}.ora"
  scp -p "${CUSTOM_ORACLE_TEMP_DIR}/init${ORACLE_SID}.ora" "${STANDBY_SSH}:${STANDBY_ORACLE_HOME}/dbs/"
}

function startStandbyNomount {
  ssh "${STANDBY_SSH}" bash -s <<EOF | tee -a "${LOG_FILE_NAME}"
export ORACLE_HOME=${STANDBY_ORACLE_HOME} ORACLE_SID=${ORACLE_SID}
\$ORACLE_HOME/bin/sqlplus -s / as sysdba <<'SQL'
startup nomount pfile='${STANDBY_ORACLE_HOME}/dbs/init${ORACLE_SID}.ora'
exit
SQL
EOF
}

function rmanDuplicate {
  # '>' not '>>' so a re-run does not append a second DUPLICATE command
  cat > "${CUSTOM_ORACLE_TEMP_DIR}/active_duplicate.cmd" <<EOF
DUPLICATE TARGET DATABASE
  FOR STANDBY
  FROM ACTIVE DATABASE
  DORECOVER
  SPFILE
    SET db_unique_name='${STANDBY_DB_NAME}' COMMENT 'Is standby'
    SET log_archive_dest_2='SERVICE=${PRIMARY_DB_NAME} ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=${PRIMARY_DB_NAME}'
    SET fal_server='${PRIMARY_DB_NAME}' COMMENT 'Is primary'
  NOFILENAMECHECK;
EOF
  cat "${CUSTOM_ORACLE_TEMP_DIR}/active_duplicate.cmd" | tee -a "${LOG_FILE_NAME}"
  # run from the primary: target = primary, auxiliary = standby (NOMOUNT, via static listener entry)
  rman target "${DBA_USERNAME}/\"${DBA_PASSWORD}\"@${PRIMARY_DB_NAME}" \
       auxiliary "${DBA_USERNAME}/\"${DBA_PASSWORD}\"@${STANDBY_DB_NAME}" \
       cmdfile="${CUSTOM_ORACLE_TEMP_DIR}/active_duplicate.cmd" | tee -a "${LOG_FILE_NAME}"
}

function startMrp {
  ssh "${STANDBY_SSH}" bash -s <<EOF | tee -a "${LOG_FILE_NAME}"
export ORACLE_HOME=${STANDBY_ORACLE_HOME} ORACLE_SID=${ORACLE_SID}
\$ORACLE_HOME/bin/sqlplus -s / as sysdba <<'SQL'
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE USING CURRENT LOGFILE DISCONNECT FROM SESSION;
exit
SQL
EOF
}

# | SCRIPT STARTS HERE                                                         |
# +----------------------------------------------------------------------------+
wl "START TIME: ${START_DATE}"
verifyOSUserLogin
checkScriptAlreadyRunning

banner "SCRIPT VARIABLES"
wl "SCRIPT            : ${SCRIPT_NAME}"
wl "HOST NAME         : ${HOSTNAME}"
wl "LOG FILE          : ${LOG_FILE_NAME}"
wl "ORACLE_SID        : ${ORACLE_SID}"
wl "PRIMARY_DB_NAME   : ${PRIMARY_DB_NAME} on ${PRIMARY_HOST_NAME}"
wl "STANDBY_DB_NAME   : ${STANDBY_DB_NAME} on ${STANDBY_HOST_NAME}"
wl "DBA_USERNAME      : ${DBA_USERNAME} (password ${HIDE_PASSWORD_STRING})"

banner "WARNING"
wl "This script creates a physical standby (${STANDBY_DB_NAME}) of ${PRIMARY_DB_NAME}"
wl "on ${STANDBY_HOST_NAME} using RMAN DUPLICATE ... FROM ACTIVE DATABASE."
wl "Prerequisites: passwordless ssh to ${STANDBY_SSH}; Oracle software installed"
wl "on the standby at ${STANDBY_ORACLE_HOME}; an oratab entry for ${ORACLE_SID} there."
askYesNo "Continue and create the standby database?"

banner "TEST LOGIN TO PRIMARY DATABASE"
verifyDatabaseLoginCredentials "${PRIMARY_DB_NAME}" "${DBA_USERNAME}" "${DBA_PASSWORD}" SYSDBA

banner "ARCHIVELOG / FORCE LOGGING / PARAMETERS ON PRIMARY"
archiveLogging
forceLogging
initializationParams

banner "STANDBY DIRECTORIES, LISTENER AND TNS"
standbyDirectories
standbyListener
tnsEntries
verifyTNSConnectString "${PRIMARY_DB_NAME}"
verifyTNSConnectString "${STANDBY_DB_NAME}"
verifyTnsFromStandby

banner "STANDBY REDO LOGS, PASSWORD FILE, PFILE"
standbyRedo
copyPasswordFile
standbyPfile

banner "START STANDBY INSTANCE IN NOMOUNT"
startStandbyNomount
verifyDatabaseLoginCredentials "${STANDBY_DB_NAME}" "${DBA_USERNAME}" "${DBA_PASSWORD}" SYSDBA

banner "RMAN ACTIVE DUPLICATE FOR STANDBY"
rmanDuplicate

banner "START MANAGED RECOVERY (REAL-TIME APPLY)"
startMrp

banner "ENABLE REDO TRANSPORT AND SWITCH LOGFILE ON PRIMARY"
runSql <<'EOF'
alter system set log_archive_dest_state_2=enable scope=both;
alter system switch logfile;
EOF

banner "SCAN LOG FILE FOR EXCEPTIONS"
if grep -E 'ORA-|RMAN-' "${LOG_FILE_NAME}" | grep -vE 'RMAN-20242|RMAN-00571|RMAN-00569|RMAN-03002|RMAN-07529|RMAN-07517|RMAN-05538'; then
  wl "---> ERRORS WERE FOUND <---"
  ERRORS="YES"
else
  wl "TRACE> No exceptions were found."
  ERRORS="NO"
fi

banner "REMOVE SCRIPT LOGS OLDER THAN ${LOG_FILE_ARCHIVE_OBSOLETE_DAYS} DAYS"
find "${CUSTOM_ORACLE_LOG_DIR}/" -name "${SCRIPT_NAME_NOEXT}_${HOSTNAME_SHORT_UPPER}_*.log" \
     -mtime +${LOG_FILE_ARCHIVE_OBSOLETE_DAYS} -exec ls -l {} \; -exec rm -f {} \; | tee -a "${LOG_FILE_NAME}"

if [[ ${ERRORS} == "YES" ]]; then
  finish "FAILED"
else
  finish "SUCCESSFUL"
fi

Verify the Standby

SQL
-- on the standby
select database_role, open_mode, protection_mode from v$database;
select process, status, thread#, sequence# from v$managed_standby;   -- MRP0 = APPLYING_LOG
select name, value from v$dataguard_stats;                           -- transport / apply lag

-- on the primary
select dest_id, status, error from v$archive_dest_status where dest_id = 2;

Once it's running, consider adding the Data Guard broker (dg_broker_start=true and dgmgrl) — it makes switchover, failover and monitoring much easier.

Changes from My Original Version

I cleaned the script up while moving it here. The main fixes:

  • Parameters didn't take effect. They were set with scope=spfile and the database was never restarted. They're now SCOPE=BOTH (except REMOTE_LOGIN_PASSWORDFILE), and the broken DG_CONFIG=(sunkdev",sunksbdev") quoting is fixed.
  • Standby redo logs were created with ADD LOGFILE — that adds online redo log groups. It's now ADD STANDBY LOGFILE.
  • Password file — it was never copied to the standby, so redo transport and the RMAN auxiliary connection would fail. Added.
  • Remote checks ran locally. The tnsping test sent to the standby used an unquoted heredoc, so $? was expanded on the primary before ssh ran, and it called an undefined errorExit. It's now a quoted heredoc and fails the script properly.
  • The RMAN command file was appended (>>), so a second run had two DUPLICATE commands; it's overwritten now. RMAN runs from the primary with cmdfile=, and redo transport is deferred until the standby exists.
  • Managed recovery now uses real-time apply; FAL_CLIENT is dropped (deprecated since 11.2).
  • Shell bugs: #!/bin/sh → #!/bin/bash (it uses bash syntax), tr -d "/t/n/r" (deleted the letters t, n, r) replaced, the id | awk -F( syntax error replaced with id -un, broken find -exec … ; and undefined $LS_BIN/$RM_BIN fixed, banner variables that were never set removed, and the hostname variables are set before they're used.
  • Password and email addresses replaced with placeholders.
The structure of this script — the logging function, run-flag file, credential checks and email-on-exit — follows Jeffrey M. Hunter's Oracle DBA shell scripts from idevelopment.info, which I adapted to build a standby.
