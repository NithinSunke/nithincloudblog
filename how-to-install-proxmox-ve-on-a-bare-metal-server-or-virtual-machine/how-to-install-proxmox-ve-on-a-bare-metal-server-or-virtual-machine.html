How to Install Proxmox VE on a Bare-Metal Server or Virtual Machine

By Sunke Nithin · April 22, 2025   VirtualizationProxmoxInstallation

Proxmox VE is an open-source virtualization platform (KVM virtual machines and LXC containers) with a web UI, clustering, HA and built-in backup. Here I install Proxmox VE 8.4 — the same steps apply on a physical server or nested in a VM for testing.

What You Need

  • The Proxmox VE ISO from proxmox.com/downloads
  • A 64-bit server with Intel VT-x/AMD-V enabled in the BIOS (for a nested lab VM, enable "expose hardware-assisted virtualization" on the VM)
  • A USB stick (physical install) — written with Rufus, balenaEtcher or dd
  • A static IP address, hostname (FQDN), gateway and DNS server

1Boot the Installer

Boot from the USB stick or mount the ISO in the VM, and choose Install Proxmox VE (Graphical):

2Installation Wizard

Accept the EULA and choose the target disk (Options lets you pick ext4, XFS or ZFS — ZFS mirrors are popular on real hardware):

Set the country, time zone and keyboard, then the root password and a notification email:

Management network: interface, hostname (FQDN), IP address/CIDR, gateway and DNS. Review the summary and click Install:

3Reboot and Log In

Remove the installation media; after the reboot the console shows the web address:

Browse to https://<Proxmox-IP>:8006 (here https://192.168.1.11:8006), accept the self-signed certificate, and log in as root with realm Linux PAM:

4Switch to the No-Subscription Repository

Without a subscription, the enterprise repository returns errors on update. In node → Updates → Repositories, Disable the enterprise repositories (pve and ceph) and Add the No-Subscription repository:

Then update:

BASH
apt update
apt full-upgrade -y
pveversion
The no-subscription repository is fine for labs and small setups; for production, a subscription gives you the tested enterprise repository and support.
