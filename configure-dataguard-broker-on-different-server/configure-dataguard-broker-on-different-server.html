Configure the Data Guard Broker from a Separate Server

By Sunke Nithin · August 8, 2022   DatabaseOracleData Guard

The Data Guard broker runs inside the databases, but you manage it with dgmgrl from any host that has an Oracle client and can reach both databases — such as a management or observer server. Here I create the broker configuration for the primary NPGR and standby NPGRSB from a third host.

The standby itself was built in Setting up a 19c physical standby with RMAN active duplicate.

1Net Entries on the Management Host

TNSNAMES.ORA
NPGR =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = orstdbdvl01.snvcloud.com)(PORT = 1521))
    (CONNECT_DATA = (SERVER = DEDICATED)(SERVICE_NAME = NPGR))
  )

NPGRSB =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = orstsbdvl01.snvcloud.com)(PORT = 1521))
    (CONNECT_DATA = (SERVER = DEDICATED)(SERVICE_NAME = NPGRSB))
  )

2Start the Broker in Both Databases

SQL
-- on primary and standby
alter system set dg_broker_start=true;
-- (optional) where the broker keeps its config files; on ASM put them in disk groups
-- alter system set dg_broker_config_file1='+DATA/NPGR/dr1npgr.dat';
-- alter system set dg_broker_config_file2='+FRA/NPGR/dr2npgr.dat';

If you set LOG_ARCHIVE_DEST_2 by hand while building the standby, the broker takes it over when you add the database; you'll manage transport through broker properties from now on.

3Static Listener Entries

For switchovers the broker restarts databases, so it needs a static <db_unique_name>_DGMGRL service on each server (NPGR_DGMGRL on the primary):

LISTENER.ORA
# listener.ora on each database server (shown for the standby)
SID_LIST_LISTENER =
  (SID_LIST =
    (SID_DESC =
      (GLOBAL_DBNAME = NPGRSB_DGMGRL)
      (ORACLE_HOME = /h01/oracle/19cr3)
      (SID_NAME = NPGRSB)
    )
  )

4Create and Enable the Configuration

From the management host — let DGMGRL prompt for the password rather than putting it on the command line:

DGMGRL
$ dgmgrl sys@NPGR                 # prompts for the SYS password
Connected to "NPGR"
Connected as SYSDBA.

DGMGRL> create configuration my_dg_config as primary database is npgr connect identifier is npgr;
Configuration "my_dg_config" created with primary database "npgr"

DGMGRL> add database npgrsb as connect identifier is npgrsb maintained as physical;
Database "npgrsb" added

DGMGRL> enable configuration;
Enabled.
