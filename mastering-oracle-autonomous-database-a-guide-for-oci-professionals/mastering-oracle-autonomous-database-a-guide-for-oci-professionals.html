Mastering Oracle Autonomous Database: A Guide for OCI Professionals

By Sunke Nithin · April 4, 2025   DatabaseOCIADB

Oracle Autonomous Database (ADB) is Oracle's fully managed database service on Oracle Cloud Infrastructure (OCI). Provisioning, patching, backups, tuning and scaling are automated, so you spend your time on data and applications instead of maintenance. This is an overview of what it offers and the day-to-day tasks you still do yourself.

What Is Autonomous Database?

ADB is a self-driving, self-securing, self-repairing Oracle Database. It comes in workload types tuned for different jobs — Transaction Processing (OLTP and mixed), Data Warehouse, JSON and APEX — on shared (Serverless) or dedicated Exadata infrastructure. You size it in ECPUs and storage, and pay for what you use.

Key Features

Built-in Tools (Database Actions)

The web console that comes with every ADB:

  • SQL Worksheet — run SQL and PL/SQL
  • Data Load — load files or cloud storage data into tables
  • Data Modeler — design and view data models
  • REST — publish tables and queries as RESTful services
  • Oracle APEX — build low-code web apps
  • Oracle Machine Learning — notebooks and AutoML
  • Graph Studio — property and RDF graphs
  • Performance Hub — ASH analytics and SQL monitoring

Operational Tasks

Lifecycle

Create, start, stop, restart and terminate from the OCI Console, the OCI CLI (oci db autonomous-database …), Terraform or the REST API.

Scale up or down

Change ECPUs or storage on demand without a service interruption.

Users and access

  • Change the ADMIN password; create application users with only the privileges they need.
  • Restrict network access with Access Control Lists (allowed IPs, CIDR blocks or VCNs) or use a private endpoint in your VCN.

Data management

  • Load data from OCI Object Storage, AWS S3, Azure Blob Storage and Google Cloud Storage with DBMS_CLOUD or Data Load.
  • Automatic backups (retention configurable from 1 to 60 days) plus manual backups; restore or clone to a point in time.
  • Clone for dev/test — full, metadata-only or refreshable clones.

Disaster Recovery

OptionWhat you get
Backup-based DRIncluded by default (local); optional cross-region backup copy. Low cost, recovery time of about an hour or more
Autonomous Data GuardA standby database, local or in another region, with a recovery time of minutes. Local standbys can fail over automatically

For the details and a walkthrough, see Oracle Autonomous Database: Disaster Recovery.

Monitoring and Alerts

  • OCI Console metrics — CPU, storage, sessions, queries.
  • Performance Hub — ASH analytics, SQL monitoring and blocking sessions.
  • Alarms — notify on high CPU or storage, or failed connections, through OCI Notifications.

Security and Performance

  • Data is always encrypted at rest and in transit.
  • Register with Oracle Data Safe for security assessments, user assessments, activity auditing and data masking.
  • Control public access with ACLs, or keep the database on a private endpoint.
  • Automatic indexing (a performance feature) creates and drops indexes based on the workload — enable it with DBMS_AUTO_INDEX.

Final Thoughts

Autonomous Database takes the routine work — patching, backups, tuning, scaling — off the DBA's plate, and adds built-in tools from APEX to machine learning. What's left is the work that matters: data modelling, security, access and making sure applications use it well.
