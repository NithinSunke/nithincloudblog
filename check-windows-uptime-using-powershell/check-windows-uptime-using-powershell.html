Check Windows Uptime Using PowerShell

By Sunke Nithin · August 16, 2025   WindowsScripts

How long has this server been up since its last reboot? For troubleshooting and patch compliance that's a question you ask all the time. Task Manager shows it for one machine; PowerShell answers it for one or a hundred, in a form you can script.

The Last Boot Time

The Win32_OperatingSystem CIM class records when Windows last started:

POWERSHELL
(Get-CimInstance Win32_OperatingSystem).LastBootUpTime

A Small Uptime Script

UPTIME.PS1
# uptime.ps1 - last boot time and uptime
$lastBoot = (Get-CimInstance -ClassName Win32_OperatingSystem).LastBootUpTime
$uptime   = (Get-Date) - $lastBoot

"System last boot : {0}" -f $lastBoot
"System uptime    : {0} days {1} hours {2} minutes {3} seconds" -f `
    $uptime.Days, $uptime.Hours, $uptime.Minutes, $uptime.Seconds
POWERSHELL
.\uptime.ps1
OUTPUT
System last boot : 8/10/2025 2:45:12 PM
System uptime    : 6 days 21 hours 11 minutes 15 seconds

If scripts are blocked, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once.

Shorter on PowerShell 7

POWERSHELL
# PowerShell 7+: built-in cmdlet
Get-Uptime
Get-Uptime -Since          # last boot time

Many Servers

POWERSHELL
# several servers at once (WinRM/CIM must be allowed)
$servers = 'SRV01','SRV02','SRV03'
Get-CimInstance -ClassName Win32_OperatingSystem -ComputerName $servers |
  Select-Object PSComputerName, LastBootUpTime,
    @{n='UptimeDays'; e={ [math]::Round(((Get-Date) - $_.LastBootUpTime).TotalDays, 1) }} |
  Sort-Object UptimeDays -Descending

Why Did It Reboot?

POWERSHELL
# who/what restarted the machine (event 1074 = planned restart/shutdown)
Get-WinEvent -FilterHashtable @{LogName='System'; Id=1074} -MaxEvents 5 |
  Select-Object TimeCreated, Message
With Fast Startup enabled (the default on Windows 10/11 desktops), "Shut down" hibernates the kernel instead of restarting it, so uptime keeps counting across shutdowns. Only Restart resets it. Servers don't use Fast Startup.
