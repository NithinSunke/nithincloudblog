Features of Amazon EC2

By Sunke Nithin · July 30, 2019   CLOUDAWS

Amazon Elastic Compute Cloud (EC2) gives you virtual servers in AWS that you can start in minutes and pay for only while they run. These are the building blocks you work with when you launch one.

FeatureWhat it is
InstancesThe virtual servers themselves
Amazon Machine Images (AMIs)Templates containing the operating system and any pre-installed software an instance boots from
Instance typesPre-set combinations of CPU, memory, storage and network performance — general purpose, compute-, memory- or storage-optimized, GPU
Key pairsSSH/RDP login: AWS keeps the public key, you keep the private key safe
Instance store volumesFast local disks whose data is lost when the instance stops or terminates
Amazon EBS volumesPersistent network block storage that survives stops, with snapshots for backup
Regions and Availability ZonesGeographic areas and isolated data centres within them, for placing resources and spreading them for resilience
Security groupsStateful virtual firewalls that set which protocols, ports and source addresses can reach an instance
Elastic IP addressesStatic public IPv4 addresses you can move between instances (charged per hour)
TagsKey-value labels for organizing resources and tracking cost
Virtual Private Cloud (VPC)Your own isolated network in AWS, optionally connected to your on-premises network

A Few More Worth Knowing

  • Purchase options — On-Demand, Savings Plans/Reserved Instances for steady workloads, and Spot Instances at a deep discount for interruptible work.
  • Auto Scaling groups — add and remove instances automatically with demand.
  • IAM roles for EC2 — give an instance AWS permissions without storing access keys on it.
  • Systems Manager Session Manager — shell access without opening SSH ports.
