How to Restore a VM from a Proxmox Backup Server (PBS) Backup as a New VM

By Sunke Nithin · April 22, 2025   VirtualizationProxmox

With Proxmox Backup Server connected to Proxmox VE, restoring a VM is a few clicks — either over the original VM, or as a brand-new VM for testing, cloning or recovering files without touching the original.

Prerequisites

  • Proxmox VE connected to PBS (see the series links below)
  • A backup of the VM in PBS
  • Enough free space on the target storage

1Find the Backup

In Proxmox VE, select the PBS storage (e.g. pbs (pve)) → Backups. Backups are listed by VM ID, type and date:

2Restore

Select the backup and click Restore:

OptionMeaning
StorageWhere the disks go; From backup configuration uses the original storage
VMThe target VM ID. The original ID overwrites that VM; a new ID creates a new VM (I restored VM 102 as 103)
UniqueGenerate new MAC addresses and other unique IDs — tick it when the original VM still exists
Start after restoreBoot the VM when the restore finishes
Live restoreStart the VM immediately and stream data in the background (quick recovery, slower at first)
Override settingsChange the name, memory, cores and sockets of the restored VM

3Watch the Task

The task log shows the disks being restored; it ends with TASK OK:

4Start and Check the VM

Select the new VM → Start → Console. If the original is still running, change the clone's hostname and IP address before connecting it to the same network.

Need just a few files, not a whole VM? Use File Restore on the backup to browse and download them.

When to Restore

  • Recovering a failed or deleted VM
  • Proving your backups work — schedule regular test restores
  • Making a copy for staging, UAT or a lab
