How to Disable and Enable Default Maintenance Jobs in Oracle Database

By Sunke Nithin · April 16, 2025   DatabaseOracle

Oracle runs three automated maintenance tasks in its nightly and weekend maintenance windows. They keep the database healthy, but during a migration, a performance test or a busy batch period you may want them out of the way for a while. DBMS_AUTO_TASK_ADMIN turns them off and on.

The Three Tasks

Client nameWhat it does
auto optimizer stats collectionGathers stale and missing optimizer statistics
auto space advisorRuns the Segment Advisor to find space to reclaim
sql tuning advisorTunes the top resource-intensive SQL statements

Use these exact names — they are what the package expects.

1Check Their Status

SQL
set lines 300 pages 3000
col client_name for a40
col status for a15
select client_name, status from dba_autotask_client;

2Disable Them

SQL
BEGIN
  dbms_auto_task_admin.disable(client_name => 'sql tuning advisor',              operation => NULL, window_name => NULL);
  dbms_auto_task_admin.disable(client_name => 'auto space advisor',              operation => NULL, window_name => NULL);
  dbms_auto_task_admin.disable(client_name => 'auto optimizer stats collection', operation => NULL, window_name => NULL);
END;
/

3Enable Them Again

SQL
BEGIN
  dbms_auto_task_admin.enable(client_name => 'sql tuning advisor',              operation => NULL, window_name => NULL);
  dbms_auto_task_admin.enable(client_name => 'auto space advisor',              operation => NULL, window_name => NULL);
  dbms_auto_task_admin.enable(client_name => 'auto optimizer stats collection', operation => NULL, window_name => NULL);
END;
/

More Control

Switch off a task in just one window, or everything at once:

SQL
-- which windows each task runs in
select window_name, autotask_status, optimizer_stats, segment_advisor, sql_tune_advisor
from   dba_autotask_window_clients;

-- disable a task in one window only (e.g. keep weekend stats, skip Monday)
BEGIN
  dbms_auto_task_admin.disable(client_name => 'auto optimizer stats collection',
                               operation   => NULL,
                               window_name => 'MONDAY_WINDOW');
END;
/
SQL
exec dbms_auto_task_admin.disable;   -- all automated maintenance tasks
exec dbms_auto_task_admin.enable;
In a multitenant database these settings are per container: run the commands in each PDB (and in the root) you want to change.

Notes

  • Re-enable the tasks as soon as the activity is over. A database without statistics gathering ends up with stale stats and bad execution plans.
  • Often the better fix is to move or shorten the maintenance windows (DBMS_SCHEDULER.SET_ATTRIBUTE on MONDAY_WINDOW … SUNDAY_WINDOW) instead of disabling the tasks.
