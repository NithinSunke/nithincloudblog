Dropping a Database in MongoDB

By Sunke Nithin · August 25, 2025   DatabaseMongoDB

This guide explains how to drop (delete) a MongoDB database using the mongosh shell. We'll use the myDatabase database created previously and the mongoadmin user for authentication. Dropping a database is a destructive action, so proceed with caution.

1Prerequisites

  • MongoDB 8.0 Community Edition installed.
  • An admin user (mongoadmin) with the readWriteAnyDatabase and userAdminAnyDatabase roles.
  • The MongoDB service running (sudo systemctl status mongod).
  • mongosh installed (included with mongodb-org).
  • MongoDB Compass installed (optional, for a GUI).
  • For remote access: bindIp set in /etc/mongod.conf (e.g. 0.0.0.0) and port 27017 open.
  • A backup of any critical data before you drop anything (e.g. with mongodump).

2Important Warning: Back Up First

Irreversible. Dropping a database permanently deletes it along with all its collections and documents. There is no undo.

Always create a backup before proceeding:

BASH
mongodump -u mongoadmin --authenticationDatabase admin --db myDatabase --out /path-to-backup

3Dropping a Database Using mongosh

The mongosh shell provides a straightforward command to drop a database.

Step 1Connect to MongoDB

Connect as the mongoadmin user:

BASH
mongosh -u mongoadmin -p --authenticationDatabase admin

Enter the password when prompted. You'll see the admin> prompt.

Step 2Verify the Database Exists

List the available databases to confirm the target database exists:

MONGOSH
show databases

Step 3Drop the Database

Switch to the database you want to delete (e.g. myDatabase):

MONGOSH
use myDatabase

Drop the database:

MONGOSH
db.dropDatabase()

This deletes myDatabase and all its collections.

db.dropDatabase() drops whichever database you are currently in. Check the prompt shows the right name (here myDatabase>) before you press Enter.

Step 4Confirm Deletion

MONGOSH
show databases

myDatabase should no longer appear.

Step 5Exit the Shell

MONGOSH
exit

4Troubleshooting

Permission denied (Unauthorized)

If dropDatabase() fails like this:

MONGOSH
test> use myDatabase
switched to db myDatabase
myDatabase> db.dropDatabase()
MongoServerError[Unauthorized]: not authorized on myDatabase to execute command { dropDatabase: 1, lsid: { id: UUID("c0782ad2-d8d6-40f4-b661-dc8478569459") }, $db: "myDatabase" }

Check the user's existing privileges:

MONGOSH
myDatabase> db.runCommand({ connectionStatus: 1 })
{
  authInfo: {
    authenticatedUsers: [ { user: 'mongoadmin', db: 'admin' } ],
    authenticatedUserRoles: [
      { role: 'readWriteAnyDatabase', db: 'admin' },
      { role: 'userAdminAnyDatabase', db: 'admin' }
    ]
  },
  ok: 1
}
Why it fails: readWriteAnyDatabase lets a user read and write data in any database, but it does not include the dropDatabase action. That action comes from dbAdmin (or dbAdminAnyDatabase, dbOwner, root).

Grant the right role

Switch to the admin database and grant your user the required privilege:

MONGOSH
use admin
db.grantRolesToUser(
  "mongoadmin",
  [ { role: "dbAdmin", db: "myDatabase" } ]
)

Or, if you want full access to that database:

MONGOSH
db.grantRolesToUser(
  "mongoadmin",
  [ { role: "readWrite", db: "myDatabase" }, { role: "dbAdmin", db: "myDatabase" } ]
)

Then run use myDatabase and db.dropDatabase() again.

5Best Practices

  • Back up first: always back up critical databases with mongodump before dropping:
    BASH
    mongodump -u mongoadmin --authenticationDatabase admin --db myDatabase --out /path/to/backup
  • Double-check the database name: make sure you're dropping the correct database — the action is irreversible.
  • Restrict access: use specific users with limited roles for non-admin tasks, to prevent accidental deletions.
  • Audit logs: enable auditing to track database operations for accountability (built in to MongoDB Enterprise and Atlas; not available in Community Edition).

Conclusion

You've learned how to drop a MongoDB database (myDatabase) using mongosh. This is a critical operation, so always verify the database name and back up the data beforehand. For further details, see the MongoDB documentation for db.dropDatabase().
