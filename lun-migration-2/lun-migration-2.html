Moving OCR and Voting Disks from the Present LUN to a New LUN

By Sunke Nithin · June 26, 2019   LinuxStorage

The Oracle Cluster Registry (OCR) and the voting disks live in an ASM disk group. When their LUNs are being retired, both can be moved to a new disk group online — the cluster keeps running. Here I move them from +DATA to a new +OCR disk group on new LUNs.

First prepare the new LUNs and create the +OCR disk group — see LUN Migration: Adding New LUNs to Oracle ASM. Use NORMAL redundancy with three disks (three failure groups) so there are three voting files, and compatible.asm of at least 11.2.

1Check the New Disk Group Is Mounted Everywhere

BASH
$ asmcmd lsdg
State    Type    Rebal  Sector  Block       AU  Total_MB  Free_MB  Req_mir_free_MB  Usable_file_MB  Offline_disks  Voting_files  Name
MOUNTED  NORMAL  N         512   4096  1048576     40944    25698            10236            7731              0             Y  DATA/
MOUNTED  NORMAL  N         512   4096  1048576      6141     5730             2047            1841              0             N  OCR/

Run asmcmd lsdg and asmcmd lsdsk on each node. If +OCR isn't mounted on every node, crsctl replace votedisk fails with CRS-4602: Failed 27 to add voting file. Mount it with srvctl start diskgroup -diskgroup OCR.

2Back Up the OCR

ROOT
# $GRID_HOME/bin/ocrconfig -manualbackup
# $GRID_HOME/bin/ocrconfig -showbackup

3Relocate the OCR

As root, check the current location:

ROOT
# $GRID_HOME/bin/ocrcheck
Status of Oracle Cluster Registry is as follows :
         Version                  :          3
         Total space (kbytes)     :     262120
         Used space (kbytes)      :       3664
         Available space (kbytes) :     258456
         ID                       :  630679368
         Device/File Name         :      +DATA
                                    Device/File integrity check succeeded

Add +OCR as a second location — the OCR is now kept in both:

ROOT
# $GRID_HOME/bin/ocrconfig -add +OCR
# $GRID_HOME/bin/ocrcheck
...
         Device/File Name         :      +DATA
                                    Device/File integrity check succeeded
         Device/File Name         :       +OCR
                                    Device/File integrity check succeeded

Then remove the old location:

ROOT
# $GRID_HOME/bin/ocrconfig -delete +DATA
# $GRID_HOME/bin/ocrcheck
...
         Device/File Name         :       +OCR
                                    Device/File integrity check succeeded

4Relocate the Voting Disks

Check where they are now:

ROOT
# $GRID_HOME/bin/crsctl query css votedisk
##  STATE    File Universal Id                File Name                  Disk group
--  -----    -----------------                ---------                  ---------
 1. ONLINE   7c7a1eb193644fc3bffd655ae8e43462 (/dev/asmdisk1_udev_sdb1) [DATA]
 2. ONLINE   6590ede5237e4f37bfe6aa3d196fe972 (/dev/asmdisk2_udev_sdc1) [DATA]
 3. ONLINE   3a7c7b334faf4fdcbf05a246eddf5404 (/dev/asmdisk3_udev_sdd1) [DATA]
Located 3 voting disk(s).

Voting files in ASM are moved as a group with one command (as the grid owner or root):

BASH
$ $GRID_HOME/bin/crsctl replace votedisk +OCR
Successful addition of voting disk 0850980df1024fcfbfc077b9c6935a17.
Successful addition of voting disk 0ca6719843734f16bfb62f22f94f399c.
Successful addition of voting disk 4383a5ad43324fa2bff759ce20ba0c3f.
Successful deletion of voting disk 10c81d1ce5a14fb6bf35cbb22fff3ebf.
Successful deletion of voting disk 98010612be6b4fc9bf3bc1b186d8758d.
Successful deletion of voting disk 9688bec3914d4f70bfc959664ddd8584.
Successfully replaced voting disk group with +OCR.
CRS-4266: Voting file(s) successfully replaced

$ $GRID_HOME/bin/crsctl query css votedisk
##  STATE    File Universal Id                File Name                  Disk group
--  -----    -----------------                ---------                  ---------
 1. ONLINE   b0e94e5d83054fe9bf58b6b98bfacd65 (/dev/asmdisk5_udev_sdf1) [OCR]
 2. ONLINE   88c2a08b4c8c4f85bf0109e0990388e4 (/dev/asmdisk6_udev_sdg1) [OCR]
 3. ONLINE   1108f9a41e814fb2bfed879ff0039dd0 (/dev/asmdisk7_udev_sdh1) [OCR]
Located 3 voting disk(s).

The three voting files are now on the three disks of +OCR.

5Final Checks

BASH
# $GRID_HOME/bin/ocrcheck
$ crsctl query css votedisk
$ crsctl check cluster -all
$ crsctl stat res -t
  • If you're removing the old disk group entirely, also move the ASM spfile (asmcmd spmove) and password file (asmcmd pwmove) off it, and check nothing else is stored there.
  • Take a fresh OCR backup now that it lives in the new location.
